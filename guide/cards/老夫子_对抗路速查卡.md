# 老夫子（对抗路）速查卡

> 万古长明 · 战士 · 官方分路：对抗路 · 快照 2026-11-12

## 实战连招（按顺序按）

- **对线换血消耗**：`1技能`
  - 在对方技能真空期打满伤害
  - 注意：技能落空后仍继续前压，换血变单方面挨打
- **追击与残血收割**：`3技能 → 1技能`
  - 把已经交掉关键技能的残血目标彻底收掉
  - 注意：位移留到残血才交，目标一个闪现或加速就脱离，交空后你被反打
- **残血逃生保命**：`3技能`
  - 拉开距离，把命保住而不是换人头
  - 注意：朝敌人方向交位移，等于主动送进控制范围
- **拆塔与清线**：`1技能`
  - 把优势转成塔与经济，而不是无意义换人头
  - 注意：把范围技能浪费在兵线上，或在对方塔下强开导致被反杀
- 官方连招原文：圣人训诫-举一反三-圣人之威（基础连招）　/　圣人之威-圣人训诫-举一反三（爆发连招）

### 对抗路打法（这条英雄专属打法）

| 节点 | 做法 | 为什么 |
| --- | --- | --- |
| 抢线 | 开局用【圣人训诫】快速推线，把对方逼到塔下再打消耗 | 对抗路先手推线的人拥有换血主动权 |
| 换血后撤 | 用【圣人之威】拉开距离后立刻往回走，不要在换血后站着对拼 | 老夫子向指定方向冲锋造成物理伤害，拉开之后是你回身打第二轮 |
| 压塔时机 | 【圣人之威】用来压塔或逼对方回城，等对方位移交掉再顶上去 | 老夫子向指定方向冲锋造成物理伤害，顶在塔前逼位能直接拆塔 |
| 转线支援 | 对方打野在中路消失就往中路靠，抢支援比补线值钱 | 对抗路转线晚一步，团战就是少一个人 |
| 单带 | 队友抱团时你在边路单带，不要跟着去挤团 | 团战你不在也能打，单带你不在就丢高地 |
