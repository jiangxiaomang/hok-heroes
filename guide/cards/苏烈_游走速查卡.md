# 苏烈（游走）速查卡

> 不屈铁壁 · 辅助 · 官方分路：游走、对抗路 · 快照 2026-11-12

## 实战连招（按顺序按）

- **团战开团先手**：`1技能 → 3技能`
  - 用最短时间把对方关键位控住，把先手权换成团战收益
  - 注意：硬控落空或被对方前排挡下，后面所有技能都变成空放
- **草丛埋伏突袭**：`1技能`
  - 用草丛消除对方反应时间，靠控制先手换血或击杀
  - 注意：从草丛正面走出才放技能，等于告诉对方「草里有人」，对方会提前交位移
- **对线换血消耗**：`1技能`
  - 用最低成本的技能起手，确认对方状态后再决定是否打满
  - 注意：第一段落空后继续按后续技能，等于把所有技能一次性交到空气上
- **拆塔与清线**：`3技能`
  - 把优势转成塔与经济，而不是无意义换人头
  - 注意：把范围技能浪费在兵线上，或在对方塔下强开导致被反杀
- 官方连招原文：2所向披靡-3大招豪烈万军-1烽烟踏破　/　1-2-3（控制链）

## 游走位打法要点

### 蹲草与藏视野

| 站位 | 要点 | 为什么 |
| --- | --- | --- |
| 河道草丛 | 蹲守边缘，不要站草丛正中 | 草丛边缘既能看到对方来向，又能在对方进草丛前先看到人影 |
| 己方野区入口 | 打完野顺手插眼，别把视野只放在河道 | 河道有眼不等于安全，对方可从侧面野区直接进塔 |
| 对方野区盲区 | 没有视野信息时不要主动进 | 盲区里的信息为零，等于把先手权交给对方 |

### 游走路线与保护职责

| 节点 | 动作 | 原因 |
| --- | --- | --- |
| 开局 | 跟着打野的第一波入侵或第一波抓人进场 | 游走的价值在于让打野敢抓人 |
| 游走路线 | 优先游走对方射手与中路之间 | 这条线最容易出事，也最容易救 |
| 视野布置 | 把视野放在对方进攻方向，而不是自家野区 | 视野要放在对方来的方向才有价值 |

### 保护人的具体做法

| 场景 | 做法 | 原因 |
| --- | --- | --- |
| 护 C 位 | 站在己方 C 位与对方之间 | 对方要打 C 位必须先穿过你 |
| 先手开团 | 己方有人能开团时，你在侧面接第二段控制 | 双开团比单开团更难被反打 |
| 反开团 | 对方开团落地后再交控制 | 这时对方没有净化与位移 |
