# 杨玉环（中路）速查卡

> 霓裳风华 · 法师 · 官方分路：中路、游走、打野 · 快照 2026-11-12

## 实战连招（按顺序按）

- **团战开团先手**：`2技能 → 3技能 → 1技能`
  - 用最短时间把对方关键位控住，把先手权换成团战收益
  - 注意：硬控落空或被对方前排挡下，后面所有技能都变成空放
- **蹲草绕后突袭**：`3技能 → 2技能 → 1技能`
  - 用位移取消读图时间，让对方来不及交控制
  - 注意：位移落点被地形卡住，或位移方向与目标相反，导致控技能甩空
- **对线换血消耗**：`1技能 → 2技能`
  - 用最低成本的技能起手，确认对方状态后再决定是否打满
  - 注意：第一段落空后继续按后续技能，等于把所有技能一次性交到空气上
- **追击与残血收割**：`3技能 → 1技能 → 2技能`
  - 把已经交掉关键技能的残血目标彻底收掉
  - 注意：位移留到残血才交，目标一个闪现或加速就脱离，交空后你被反打
- 官方连招原文：霓裳曲-胡旋乐-长恨歌（基础连招）　/　长恨歌-霓裳曲-胡旋乐（爆发连招）

### 中路节奏（这条英雄专属打法）

| 节点 | 做法 | 为什么 |
| --- | --- | --- |
| 清线优先 | 先把兵线清完再去支援，支援路上顺手用【霓裳曲】收掉兵线再进场 | 中路线权没了就去支援，等于有去无回 |
| 消耗距离 | 用【长恨歌】打完就撤，别站在原地被人打 | 打完就跑是法师的保命方式，比护盾更实用 |
| 抢支援窗口 | 看到边路交火，在对方技能交空后用【胡旋乐】先手控住，不是开团了就到 | 早到 5 秒是接盘，晚到 5 秒是收尸 |
| 大招用途 | 【长恨歌】用来压塔或封走位，不要用来清兵 | 杨玉环跃向空中演奏，用在大招该解决的事情上 |
| 河道视野 | 把自己当第二个打野位，蹲对方从中路消失的路线 | 中路的视野优势来自草丛，不来自河道中央 |
