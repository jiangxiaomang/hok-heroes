# 苍（发育路）速查卡

> 苍狼末裔 · 射手 · 官方分路：发育路、打野 · 快照 2026-11-12

## 实战连招（按顺序按）

- **对线换血消耗**：`1技能`
  - 在对方技能真空期打满伤害
  - 注意：技能落空后仍继续前压，换血变单方面挨打
- **拆塔与清线**：`1技能`
  - 把优势转成塔与经济，而不是无意义换人头
  - 注意：把范围技能浪费在兵线上，或在对方塔下强开导致被反杀
- **发育路输出起手**：`1技能`
  - 在最短时间内把伤害打满，逼出对方保命技能
  - 注意：第一段落空后站在原地继续平A，被对方贴脸反打
- 官方连招原文：1-2-A-3-A-A（减速抓钩拉扯全图狼啸收割）　/　3-1-A-2（追击锁杀）

### 发育路打法（这条英雄专属节奏）

| 节点 | 做法 | 为什么 |
| --- | --- | --- |
| 发育节奏 | 前期以补刀为主，【鹰眼】能打到的兵才去打，不要为了一两个残血兵进塔 | 射手前期死一次，节奏就断了，等级和装备都会落后 |
| 站位输出 | 站在自己塔前用【鹰眼】打最远的那个目标，优先打前排或正在打你的那个人 | 成吉思汗释放猎鹰照亮周围区域并沿途获取敌人视野，持续，站着不动输出才有安全输出 |
| 集火规则 | 团战只打一个目标，开局就打【可汗狂猎】能覆盖到的位置 | 平均伤害谁也打不死，集中才有意义 |
| 自保 | 闪现留着打断或逃命，不要用来赶路 | 赶路用走路，闪现用来保命才有价值 |
| 拆塔 | 对方回城且兵线到位时拆塔，不要在塔下与人对峙 | 拆塔收益稳定，对峙收益不稳定 |
