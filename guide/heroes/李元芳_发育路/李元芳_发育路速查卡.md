# 李元芳（发育路）速查卡

> 王都密探 · 射手 · 官方分路：发育路、打野 · 快照 2026-11-12

## 实战连招（按顺序按）

- **拆塔与清线**：`1技能`
  - 把优势转成塔与经济，而不是无意义换人头
  - 注意：把范围技能浪费在兵线上，或在对方塔下强开导致被反杀
- 官方连招原文：谍影重重-刃遁-无间刃风（基础连招）　/　无间刃风-谍影重重-刃遁（爆发连招）

### 发育路打法（这条英雄专属节奏）

| 节点 | 做法 | 为什么 |
| --- | --- | --- |
| 发育节奏 | 前期以补刀为主，【谍影重重】能打到的兵才去打，不要为了一两个残血兵进塔 | 射手前期死一次，节奏就断了，等级和装备都会落后 |
| 站位输出 | 站在自己塔前用【谍影重重】打最远的那个目标，优先打前排或正在打你的那个人 | 元芳使用暗印标记敌方目标，后爆炸对范围内敌方造成物理伤害，元芳对该目标的普通攻击，站着不动输出才有安全输出 |
| 标记优先 | 看到【谍影重重】能挂上的目标优先集火，不要平均分配伤害 | 元芳使用暗印标记敌方目标，后爆炸对范围内敌方造成物理伤害，元芳对该目标的普通攻击，标记对象承受的伤害更集中 |
| 自保 | 闪现留着打断或逃命，不要用来赶路 | 赶路用走路，闪现用来保命才有价值 |
| 拆塔 | 对方回城且兵线到位时拆塔，不要在塔下与人对峙 | 拆塔收益稳定，对峙收益不稳定 |

### 阶段节奏（前期 → 中期 → 后期）

| 阶段 | 怎么打 | 要点 |
| --- | --- | --- |
| 前期 | 前期飞镖消耗（这一阶段主要靠【谍影重重】） | 飞镖标记后爆炸伤害 |
| 中期 | 中期标记爆发（这一阶段主要靠【谍影重重】） | 2技能位移灵活 |
| 后期 | 后期大招飞轮收割（这一阶段主要靠【谍影重重】） | 大招飞轮持续伤害 |
