# 王昭君（中路）速查卡

> 冰雪之华 · 法师 · 官方分路：中路、游走 · 快照 2026-11-12

## 实战连招（按顺序按）

- **对线换血消耗**：`1技能`
  - 在对方技能真空期打满伤害
  - 注意：技能落空后仍继续前压，换血变单方面挨打
- **拆塔与清线**：`1技能`
  - 把优势转成塔与经济，而不是无意义换人头
  - 注意：把范围技能浪费在兵线上，或在对方塔下强开导致被反杀
- 官方连招原文：3大招凛冬已至-2禁锢寒霜-1凋零冰晶　/　2-1-3（冰冻连招）

### 中路节奏（这条英雄专属打法）

| 节点 | 做法 | 为什么 |
| --- | --- | --- |
| 清线优先 | 先把兵线清完再去支援，支援路上顺手用【凋零冰晶】收掉兵线再进场 | 中路线权没了就去支援，等于有去无回 |
| 消耗距离 | 只在技能命中且对方没有位移时上前消耗 | 没有距离优势时，多一次上前就多一次被抓 |
| 抢支援窗口 | 看到边路交火，对方技能交空后再到 | 对方技能空掉的那几秒才是支援窗口 |
| 大招用途 | 【凛冬已至】用来压塔或封走位，不要用来清兵 | 王昭君召唤暴风雪对范围内敌人打击造成法术伤害与冰冷效果，持续，用在大招该解决的事情上 |
| 河道视野 | 把自己当第二个打野位，蹲对方从中路消失的路线 | 中路的视野优势来自草丛，不来自河道中央 |
