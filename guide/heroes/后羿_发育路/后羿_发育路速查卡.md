# 后羿（发育路）速查卡

> 半神之弓 · 射手 · 官方分路：发育路 · 快照 2026-11-12

## 实战连招（按顺序按）

- **团战开团先手**：`3技能 → 1技能`
  - 用最短时间把对方关键位控住，把先手权换成团战收益
  - 注意：硬控落空或被对方前排挡下，后面所有技能都变成空放
- **草丛埋伏突袭**：`3技能`
  - 用草丛消除对方反应时间，靠控制先手换血或击杀
  - 注意：从草丛正面走出才放技能，等于告诉对方「草里有人」，对方会提前交位移
- **对线换血消耗**：`2技能 → 3技能`
  - 用最低成本的技能起手，确认对方状态后再决定是否打满
  - 注意：第一段落空后继续按后续技能，等于把所有技能一次性交到空气上
- **拆塔与清线**：`1技能`
  - 把优势转成塔与经济，而不是无意义换人头
  - 注意：把范围技能浪费在兵线上，或在对方塔下强开导致被反杀
- 官方连招原文：2落日余晖-3大招灼日之矢-1多重箭矢　/　3-2-1-A（先手开团）

### 发育路打法（这条英雄专属节奏）

| 节点 | 做法 | 为什么 |
| --- | --- | --- |
| 发育节奏 | 前期以补刀为主，【多重箭矢】能打到的兵才去打，不要为了一两个残血兵进塔 | 射手前期死一次，节奏就断了，等级和装备都会落后 |
| 站位输出 | 站在自己塔前用【灼日之矢】打最远的那个目标，优先打前排或正在打你的那个人 | 后羿向指定方向射出火焰箭，站着不动输出才有安全输出 |
| 集火规则 | 团战只打一个目标，开局就打【灼日之矢】能覆盖到的位置 | 平均伤害谁也打不死，集中才有意义 |
| 自保 | 闪现留着打断或逃命，不要用来赶路 | 赶路用走路，闪现用来保命才有价值 |
| 拆塔 | 对方回城且兵线到位时拆塔，不要在塔下与人对峙 | 拆塔收益稳定，对峙收益不稳定 |
