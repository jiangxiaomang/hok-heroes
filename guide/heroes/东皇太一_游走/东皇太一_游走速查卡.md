# 东皇太一（游走）速查卡

> 噬灭日蚀 · 辅助 · 官方分路：游走、对抗路 · 快照 2026-11-12

## 实战连招（按顺序按）

- **团战开团先手**：`2技能 → 3技能 → 1技能`
  - 用最短时间把对方关键位控住，把先手权换成团战收益
  - 注意：硬控落空或被对方前排挡下，后面所有技能都变成空放
- **草丛埋伏突袭**：`2技能`
  - 用草丛消除对方反应时间，靠控制先手换血或击杀
  - 注意：从草丛正面走出才放技能，等于告诉对方「草里有人」，对方会提前交位移
- **对线换血消耗**：`1技能 → 2技能`
  - 用最低成本的技能起手，确认对方状态后再决定是否打满
  - 注意：第一段落空后继续按后续技能，等于把所有技能一次性交到空气上
- **拆塔与清线**：`1技能`
  - 把优势转成塔与经济，而不是无意义换人头
  - 注意：把范围技能浪费在兵线上，或在对方塔下强开导致被反杀
- 官方连招原文：日蚀祭典-曜龙烛兆-堕神契约（基础连招）　/　堕神契约-日蚀祭典-曜龙烛兆（爆发连招）

- **[实战要点]** 大招压制换命

## 游走位打法要点

### 高分实战要点（这个英雄专属技巧）

| 要点 | 怎么用 | 口径 |
| --- | --- | --- |
| 压制无法被净化 | 记住这条：压制无法被净化，进场前先想好怎么用 | 实战要点口径 |

### 游走职责（这条英雄专属打法）

| 节点 | 做法 | 为什么 |
| --- | --- | --- |
| 保护人 | 站到己方 C 位与对方之间，用【日蚀祭典】顶住第一轮爆发 | 释放力量对周围造成法术伤害并创造出黑暗能量体在身边环绕，同时最多存在个，若已有三，你的价值是让 C 位能站住输出 |
| 蹲草开团 | 在对方必经草丛蹲着，等对方走到再交【曜龙烛兆】，控制留在能打多人或能打 C 位的位置 | 东皇太一每拥有个黑暗能量体，就可召唤条曜龙对指定方向进行范围冲击，冲击将造成法术，控制位置的收益大于控制时机 |
| 开团与反开 | 叫队友开团，你在侧面接第二段控制 | 双开团比单开团更难被反打 |
| 跟打野 | 打野在哪条线你就出现在哪条线 | 分散的游走等于没有游走 |
| 撤退信号 | C 位血量危险时立刻喊退，不要硬保 | 救不回来就一起死，亏两波 |
