# 嫦娥（中路）速查卡

> 寒月公主 · 法师 · 官方分路：中路、对抗路、打野 · 快照 2026-11-12

## 实战连招（按顺序按）

- **团战开团先手**：`1技能 → 3技能`
  - 用最短时间把对方关键位控住，把先手权换成团战收益
  - 注意：硬控落空或被对方前排挡下，后面所有技能都变成空放
- **草丛埋伏突袭**：`1技能`
  - 用草丛消除对方反应时间，靠控制先手换血或击杀
  - 注意：从草丛正面走出才放技能，等于告诉对方「草里有人」，对方会提前交位移
- **对线换血消耗**：`2技能 → 1技能`
  - 用最低成本的技能起手，确认对方状态后再决定是否打满
  - 注意：第一段落空后继续按后续技能，等于把所有技能一次性交到空气上
- **拆塔与清线**：`2技能`
  - 把优势转成塔与经济，而不是无意义换人头
  - 注意：把范围技能浪费在兵线上，或在对方塔下强开导致被反杀
- 官方连招原文：2月辰-3大招月芒-1月璇　/　1-2-3（蓝耗爆发）

## 中路位打法要点

### 高分实战要点（这个英雄专属技巧）

| 要点 | 怎么用 | 口径 |
| --- | --- | --- |
| 月芒伤害可观 | 围绕【月芒】用：月芒伤害可观 | 嫦娥解放狂暴的魔道力量提升自身移速 |
| 月之守护吸收伤害 | 打出去的技能要记得收回来，拿不回来这套循环就断了，进场前先看清还能用几次 | 来自官方实战要点 |
| 大招范围伤害 | 围绕【月芒】用：大招范围伤害 | 嫦娥解放狂暴的魔道力量提升自身移速 |
| 被动月能回复 | 先确认自己的被动条件满没满，没满就先拉扯或者清线，别硬进场 | 来自官方实战要点 |

### 中路节奏（这条英雄专属打法）

| 节点 | 做法 | 为什么 |
| --- | --- | --- |
| 清线优先 | 先把兵线清完再去支援，支援路上顺手用【月璇】收掉兵线再进场 | 中路线权没了就去支援，等于有去无回 |
| 消耗距离 | 只在技能命中且对方没有位移时上前消耗 | 没有距离优势时，多一次上前就多一次被抓 |
| 抢支援窗口 | 看到边路交火，在对方技能交空后用【月辰】先手控住，不是开团了就到 | 早到 5 秒是接盘，晚到 5 秒是收尸 |
| 大招用途 | 【月芒】用来压塔或封走位，不要用来清兵 | 嫦娥解放狂暴的魔道力量提升自身移速，用在大招该解决的事情上 |
| 河道视野 | 把自己当第二个打野位，蹲对方从中路消失的路线 | 中路的视野优势来自草丛，不来自河道中央 |
