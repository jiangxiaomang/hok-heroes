# 梦奇（对抗路）速查卡

> 入梦之灵 · 坦克 · 官方分路：对抗路、打野 · 快照 2026-11-12

## 实战连招（按顺序按）

- **团战开团先手**：`3技能 → 1技能`
  - 用最短时间把对方关键位控住，把先手权换成团战收益
  - 注意：硬控落空或被对方前排挡下，后面所有技能都变成空放
- **草丛埋伏突袭**：`3技能`
  - 用草丛消除对方反应时间，靠控制先手换血或击杀
  - 注意：从草丛正面走出才放技能，等于告诉对方「草里有人」，对方会提前交位移
- **对线换血消耗**：`1技能 → 3技能`
  - 用最低成本的技能起手，确认对方状态后再决定是否打满
  - 注意：第一段落空后继续按后续技能，等于把所有技能一次性交到空气上
- **拆塔与清线**：`1技能`
  - 把优势转成塔与经济，而不是无意义换人头
  - 注意：把范围技能浪费在兵线上，或在对方塔下强开导致被反杀
- 官方连招原文：梦境萦绕-梦力泡泡-梦境环游（基础连招）　/　梦境环游-梦境萦绕-梦力泡泡（爆发连招）

- **[实战要点]** 被动体型越大属性越强
- **[实战要点]** 大招位移可穿墙逃跑
- **[实战要点]** 1技能护盾+减速消耗

## 对抗路位打法要点

### 高分实战要点（这个英雄专属技巧）

| 要点 | 怎么用 | 口径 |
| --- | --- | --- |
| 被动体型越大属性 | 按血线情况决定进不进：血量落到被动生效的那条线再上，血多的时候进场等于白挨打 | 实战要点口径 |
| 穿墙 | 围绕【梦境环游】用：大招位移可穿墙逃跑 | 实战要点口径 |
| 减速 | 围绕【梦境萦绕】用：1技能护盾+减速消耗 | 实战要点口径 |
| 法梦奇伤害可观但 | 优先保证这一段能完整打出来，中途不要贪别的目标 | 实战要点口径 |

### 对抗路打法（这条英雄专属打法）

| 节点 | 做法 | 为什么 |
| --- | --- | --- |
| 抢线 | 开局用【梦境萦绕】快速推线，把对方逼到塔下再打消耗 | 对抗路先手推线的人拥有换血主动权 |
| 换血后撤 | 换完血立刻后撤到兵线后方，让小兵替你挡第一轮技能 | 站桩换血是对抗路最常见的死法 |
| 压塔时机 | 【梦境环游】用来压塔或逼对方回城，等对方位移交掉再顶上去 | 梦奇进行一-次梦境环游，期间持续获得质量，对路径上的敌人造成法术伤害，顶在塔前逼位能直接拆塔 |
| 转线支援 | 对方打野在中路消失就往中路靠，抢支援比补线值钱 | 对抗路转线晚一步，团战就是少一个人 |
| 单带 | 队友抱团时你在边路单带，不要跟着去挤团 | 团战你不在也能打，单带你不在就丢高地 |

### 阶段节奏（前期 → 中期 → 后期）

| 阶段 | 怎么打 | 要点 |
| --- | --- | --- |
| 前期 | 前期泡泡消耗叠被动（这一阶段主要靠【梦境环游】） | 被动体型越大属性越强 |
| 中期 | 中期大招位移开团（这一阶段主要靠【梦境环游】） | 大招位移可穿墙逃跑 |
| 后期 | 后期肉盾承伤泡泡消耗（这一阶段主要靠【梦境环游】） | 1技能护盾+减速消耗 |
