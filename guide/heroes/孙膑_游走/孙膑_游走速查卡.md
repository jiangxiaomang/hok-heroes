# 孙膑（游走）速查卡

> 逆流之时 · 辅助 · 官方分路：游走 · 快照 2026-11-12

## 实战连招（按顺序按）

- **草丛埋伏突袭**：`1技能`
  - 用草丛消除对方反应时间，靠控制先手换血或击杀
  - 注意：从草丛正面走出才放技能，等于告诉对方「草里有人」，对方会提前交位移
- **对线换血消耗**：`1技能`
  - 用最低成本的技能起手，确认对方状态后再决定是否打满
  - 注意：第一段落空后继续按后续技能，等于把所有技能一次性交到空气上
- **拆塔与清线**：`1技能`
  - 把优势转成塔与经济，而不是无意义换人头
  - 注意：把范围技能浪费在兵线上，或在对方塔下强开导致被反杀
- **打断与保护队友**：`1技能`
  - 在关键动作读条时把对方打断，或在队友被追时把人拉回来
  - 注意：控制交早，对手交了净化或加速后你进入空窗
- 官方连招原文：3大招时光流逝-2时之波动-1时空爆弹　/　1-2-3（保护/加速）

## 游走位打法要点

### 高分实战要点（这个英雄专属技巧）

| 要点 | 怎么用 | 口径 |
| --- | --- | --- |
| 加速支援能力强 | 靠移动把距离拉开再打，不要站着对拼，走位比多打一下更重要 | 实战要点口径 |
| 减速 | 打出去的技能要记得收回来，拿不回来这套循环就断了，进场前先看清还能用几次 | 实战要点口径 |
| 开团 | 围绕【时光流逝】用：大招群体加速开团 | 实战要点口径 |
| 被动冷却缩减 | 先确认自己的被动条件满没满，没满就先拉扯或者清线，别硬进场 | 实战要点口径 |

### 游走职责（这条英雄专属打法）

| 节点 | 做法 | 为什么 |
| --- | --- | --- |
| 保护人 | 站到己方 C 位与对方之间，用身体挡住对方第一轮技能 | C 位死一次，团战直接结束 |
| 蹲草开团 | 在对方必经草丛蹲着，等对方走到再交【时空爆弹】，控制留在能打多人或能打 C 位的位置 | 孙膑投掷一枚炸弹，命中敌人后会附在其身上，造成法术伤害，后爆炸对范围内敌人造成法，控制位置的收益大于控制时机 |
| 开团与反开 | 对方先手落地后再交【时光流逝】，这时他们没有净化和位移 | 孙膑投掷一枚强化炸弹，命中敌人或飞行到最大距离后展开力场，对范围内敌人造成法术伤，后手开团比先手开团更稳 |
| 跟打野 | 打野在哪条线你就出现在哪条线 | 分散的游走等于没有游走 |
| 撤退信号 | C 位血量危险时立刻喊退，不要硬保 | 救不回来就一起死，亏两波 |
