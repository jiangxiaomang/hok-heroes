# 西施（中路）速查卡

> 幻纱之灵 · 法师 · 官方分路：中路 · 快照 2026-11-12

## 实战连招（按顺序按）

- **团战开团先手**：`1技能 → 3技能 → 2技能`
  - 用最短时间把对方关键位控住，把先手权换成团战收益
  - 注意：硬控落空或被对方前排挡下，后面所有技能都变成空放
- **蹲草绕后突袭**：`1技能 → 3技能 → 2技能`
  - 用位移取消读图时间，让对方来不及交控制
  - 注意：位移落点被地形卡住，或位移方向与目标相反，导致控技能甩空
- **对线换血消耗**：`2技能 → 1技能`
  - 用最低成本的技能起手，确认对方状态后再决定是否打满
  - 注意：第一段落空后继续按后续技能，等于把所有技能一次性交到空气上
- **追击与残血收割**：`1技能 → 2技能`
  - 把已经交掉关键技能的残血目标彻底收掉
  - 注意：位移留到残血才交，目标一个闪现或加速就脱离，交空后你被反打
- 官方连招原文：纱缚之印-幻纱之灵-心无旁骛（基础连招）　/　心无旁骛-纱缚之印-幻纱之灵（爆发连招）

## 中路位打法要点

### 高分实战要点（这个英雄专属技巧）

| 要点 | 怎么用 | 口径 |
| --- | --- | --- |
| 纱缚拉人改变位置 | 靠移动把距离拉开再打，不要站着对拼，走位比多打一下更重要 | 实战要点口径 |
| 大招群体拉扯 | 围绕【心无旁骛】用：大招群体拉扯 | 实战要点口径 |
| 减速 | 围绕【纱缚之印】用：1技能减速消耗 | 实战要点口径 |
| 被动强化纱缚 | 先确认自己的被动条件满没满，没满就先拉扯或者清线，别硬进场 | 实战要点口径 |

### 中路节奏（这条英雄专属打法）

| 节点 | 做法 | 为什么 |
| --- | --- | --- |
| 清线优先 | 先把兵线清完再去支援，支援路上顺手用【纱缚之印】收掉兵线再进场 | 中路线权没了就去支援，等于有去无回 |
| 消耗距离 | 用【纱缚之印】打完就撤，别站在原地被人打 | 打完就跑是法师的保命方式，比护盾更实用 |
| 抢支援窗口 | 看到边路交火，在对方技能交空后用【纱缚之印】先手控住，不是开团了就到 | 早到 5 秒是接盘，晚到 5 秒是收尸 |
| 大招用途 | 【心无旁骛】用来压塔或封走位，不要用来清兵 | 西施将法器的力量灌注到自己体内,获得持续的强化状态并刷新幻纱之灵的冷却时间，用在大招该解决的事情上 |
| 河道视野 | 把自己当第二个打野位，蹲对方从中路消失的路线 | 中路的视野优势来自草丛，不来自河道中央 |

### 阶段节奏（前期 → 中期 → 后期）

| 阶段 | 怎么打 | 要点 |
| --- | --- | --- |
| 前期 | 前期纱缚消耗（这一阶段主要靠【纱缚之印】） | 纱缚拉人改变位置 |
| 中期 | 中期纱缚拉人（这一阶段主要靠【纱缚之印】） | 大招群体拉扯 |
| 后期 | 后期大招群体控制（这一阶段主要靠【纱缚之印】） | 1技能减速消耗 |
