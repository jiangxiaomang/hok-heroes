# 刘禅（游走）速查卡

> 暴走机关 · 辅助 · 官方分路：游走 · 快照 2026-11-12

## 实战连招（按顺序按）

- **团战开团先手**：`1技能 → 3技能 → 2技能`
  - 用最短时间把对方关键位控住，把先手权换成团战收益
  - 注意：硬控落空或被对方前排挡下，后面所有技能都变成空放
- **蹲草绕后突袭**：`1技能 → 3技能 → 2技能`
  - 用位移取消读图时间，让对方来不及交控制
  - 注意：位移落点被地形卡住，或位移方向与目标相反，导致控技能甩空
- **对线换血消耗**：`2技能 → 1技能`
  - 用最低成本的技能起手，确认对方状态后再决定是否打满
  - 注意：第一段落空后继续按后续技能，等于把所有技能一次性交到空气上
- **追击与残血收割**：`1技能 → 2技能`
  - 把已经交掉关键技能的残血目标彻底收掉
  - 注意：位移留到残血才交，目标一个闪现或加速就脱离，交空后你被反打
- 官方连招原文：1小霸王护盾-2机关魔爪-3大招暴走熊猫　/　1-2-3-闪现（越塔强拆）

| 要点 | 怎么用 | 口径 |

| 护盾 | 打出去的技能要记得收回来，拿不回来这套循环就断了，进场前先看清还能用几次 | 实战要点口径 |

### 游走职责（这条英雄专属打法）

| 节点 | 做法 | 为什么 |
| --- | --- | --- |
| 保护人 | 站到己方 C 位与对方之间，用【小霸王护盾】顶住第一轮爆发 | 刘禅开启护盾发起冲锋，获得护盾并增加逐渐衰减的移速，持续，你的价值是让 C 位能站住输出 |
| 蹲草开团 | 在对方必经草丛蹲着，等对方走到再交【小霸王护盾】，控制留在能打多人或能打 C 位的位置 | 刘禅开启护盾发起冲锋，获得护盾并增加逐渐衰减的移速，持续，控制位置的收益大于控制时机 |
| 开团与反开 | 对方先手落地后再交【暴走熊猫】，这时他们没有净化和位移 | 刘禅操纵机关熊猫展开双臂持续旋转攻击，每对敌人造成物理伤害，持续，后手开团比先手开团更稳 |
| 跟打野 | 打野在哪条线你就出现在哪条线 | 分散的游走等于没有游走 |
| 撤退信号 | C 位血量危险时立刻喊退，不要硬保 | 救不回来就一起死，亏两波 |
