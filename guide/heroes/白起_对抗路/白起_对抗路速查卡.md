# 白起（对抗路）速查卡

> 最终兵器 · 坦克 · 官方分路：对抗路 · 快照 2026-11-12

## 实战连招（按顺序按）

- **团战开团先手**：`3技能 → 1技能`
  - 用最短时间把对方关键位控住，把先手权换成团战收益
  - 注意：硬控落空或被对方前排挡下，后面所有技能都变成空放
- **蹲草绕后突袭**：`3技能 → 1技能`
  - 用位移取消读图时间，让对方来不及交控制
  - 注意：位移落点被地形卡住，或位移方向与目标相反，导致控技能甩空
- **对线换血消耗**：`1技能 → 3技能`
  - 用最低成本的技能起手，确认对方状态后再决定是否打满
  - 注意：第一段落空后继续按后续技能，等于把所有技能一次性交到空气上
- **追击与残血收割**：`3技能 → 1技能`
  - 把已经交掉关键技能的残血目标彻底收掉
  - 注意：位移留到残血才交，目标一个闪现或加速就脱离，交空后你被反打
- 官方连招原文：3大招傲慢嘲讽-2死神之镰-1血之回响　/　闪现-3-2-1（强制开团）

## 精华技巧

- **[实战要点]** 大招嘲讽时间随最大生命提升
- **[实战要点]** 1技能蓄力越久伤害越高
- **[实战要点]** 嘲讽到多人可瞬间逆转团战
- **[实战要点]** 2技能拉人配合大招无缝控制
- **[官方 Tips]** 红色宿命可以增加攻速与物理防御，蓝色调和可以让白起更加灵活
- **[玩法定位]** 嘲讽坦克，傲慢嘲讽；嘲讽控制，被动回血

### 对抗路打法（这条英雄专属打法）

| 节点 | 做法 | 为什么 |
| --- | --- | --- |
| 抢线 | 开局用【血之回响】快速推线，把对方逼到塔下再打消耗 | 对抗路先手推线的人拥有换血主动权 |
| 换血后撤 | 把【死神之镰】丢出去拉开距离，走位退回时顺手把它捡回来 | 白起在指定位置召唤镰刀，后收回镰刀并拉回路径上的敌人，造成法术伤害和减速，持续，丢出去的技能不打中就是白丢 |
| 压塔时机 | 【傲慢嘲讽】用来压塔或逼对方回城，等对方位移交掉再顶上去 | 白起立即充满暗影之力，顶在塔前逼位能直接拆塔 |
| 转线支援 | 对方打野在中路消失就往中路靠，抢支援比补线值钱 | 对抗路转线晚一步，团战就是少一个人 |
| 单带 | 队友抱团时你在边路单带，不要跟着去挤团 | 团战你不在也能打，单带你不在就丢高地 |
