# 孙权（发育路）速查卡

> 定旌之谋 · 射手 · 官方分路：发育路 · 快照 2026-11-12

## 实战连招（按顺序按）

- **蹲草绕后突袭**：`3技能 → 1技能`
  - 用位移取消读图时间，让对方来不及交控制
  - 注意：位移落点被地形卡住，或位移方向与目标相反，导致控技能甩空
- **对线换血消耗**：`1技能`
  - 用最低成本的技能起手，确认对方状态后再决定是否打满
  - 注意：第一段落空后继续按后续技能，等于把所有技能一次性交到空气上
- **追击与残血收割**：`3技能 → 1技能`
  - 把已经交掉关键技能的残血目标彻底收掉
  - 注意：位移留到残血才交，目标一个闪现或加速就脱离，交空后你被反打
- **残血逃生保命**：`3技能`
  - 拉开距离，把命保住而不是换人头
  - 注意：朝敌人方向交位移，等于主动送进控制范围
- 官方连招原文：2阵地-1击退-A-3天火（阵地推进输出）　/　3-2-A-1（远距压制）

## 发育路位打法要点

### 高分实战要点（这个英雄专属技巧）

| 要点 | 怎么用 | 口径 |
| --- | --- | --- |
| 剑气射程远 | 站在对方够不到你的位置输出，保持距离比多打一下更重要 | 来自官方实战要点 |
| 江东之势加攻速 | 靠移动把距离拉开再打，不要站着对拼，走位比多打一下更重要 | 来自官方实战要点 |
| 免控 | 围绕【麾旌破阵】用：大招霸主模式免控 | 孙权执旗持续追击敌人并猛烈挥舞军旗对前方区域造成次物理伤害 |
| 被动连击强化普攻 | 先确认自己的被动条件满没满，没满就先拉扯或者清线，别硬进场 | 来自官方实战要点 |

### 发育路打法（这条英雄专属节奏）

| 节点 | 做法 | 为什么 |
| --- | --- | --- |
| 发育节奏 | 前期以补刀为主，【麾召千锋】能打到的兵才去打，不要为了一两个残血兵进塔 | 射手前期死一次，节奏就断了，等级和装备都会落后 |
| 站位输出 | 站在自己塔前用【麾召千锋】打最远的那个目标，优先打前排或正在打你的那个人 | 孙权掷出军旗对指定范围敌人造成物理伤害和减速，站着不动输出才有安全输出 |
| 标记优先 | 看到【疾弦骤羽】能挂上的目标优先集火，不要平均分配伤害 | 孙权进入【疾弦】状态，标记对象承受的伤害更集中 |
| 自保 | 闪现留着打断或逃命，不要用来赶路 | 赶路用走路，闪现用来保命才有价值 |
| 拆塔 | 对方回城且兵线到位时拆塔，不要在塔下与人对峙 | 拆塔收益稳定，对峙收益不稳定 |
