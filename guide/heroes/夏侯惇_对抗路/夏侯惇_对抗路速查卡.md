# 夏侯惇（对抗路）速查卡

> 不羁之风 · 坦克 · 官方分路：对抗路、游走、打野 · 快照 2026-11-12

## 实战连招（按顺序按）

- **团战开团先手**：`1技能 → 3技能`
  - 用最短时间把对方关键位控住，把先手权换成团战收益
  - 注意：硬控落空或被对方前排挡下，后面所有技能都变成空放
- **蹲草绕后突袭**：`3技能 → 1技能`
  - 用位移取消读图时间，让对方来不及交控制
  - 注意：位移落点被地形卡住，或位移方向与目标相反，导致控技能甩空
- **对线换血消耗**：`1技能`
  - 用最低成本的技能起手，确认对方状态后再决定是否打满
  - 注意：第一段落空后继续按后续技能，等于把所有技能一次性交到空气上
- **追击与残血收割**：`3技能 → 1技能`
  - 把已经交掉关键技能的残血目标彻底收掉
  - 注意：位移留到残血才交，目标一个闪现或加速就脱离，交空后你被反打
- 官方连招原文：豪气斩-龙卷闪-不羁之刃（基础连招）　/　不羁之刃-豪气斩-龙卷闪（爆发连招）

## 精华技巧

- **[实战要点]** 被动血量低于50%触发护盾+回复
- **[实战要点]** 大招命中英雄可二段突进
- **[实战要点]** 1技能减速+2技能护盾换血稳赚
- **[实战要点]** 真伤被动对坦克也有效
- **[官方 Tips]** 夏侯惇是一个典型的坦克英雄，红色宿命提供攻速和生命物理防御；蓝色铭文调和补充移速和生命回血，更加方便于支援游走；同时绿色鹰眼补足一些伤害
- **[玩法定位]** 真伤坦克，不羁之风；护盾真伤，位移控制

## 对抗路位打法要点

### 高分实战要点（这个英雄专属技巧）

| 要点 | 怎么用 | 口径 |
| --- | --- | --- |
| 护盾 | 按血线情况决定进不进：血量落到被动生效的那条线再上，血多的时候进场等于白挨打 | 来自官方实战要点 |
| 大招命中英雄可二 | 围绕【不羁之刃】用：大招命中英雄可二段突进 | 夏侯惇向指定目标方向扔出链刃，链刃飞向指定位置或击中敌人后会对范围内 |
| 减速 | 围绕【豪气斩】用：1技能减速技能护盾换血稳赚 | 夏侯惇挥动大刀，向指定方向斩一道刃风 |
| 真伤被动对坦克也 | 先确认自己的被动条件满没满，没满就先拉扯或者清线，别硬进场 | 来自官方实战要点 |

### 对抗路打法（这条英雄专属打法）

| 节点 | 做法 | 为什么 |
| --- | --- | --- |
| 抢线 | 开局用【豪气斩】快速推线，把对方逼到塔下再打消耗 | 对抗路先手推线的人拥有换血主动权 |
| 换血后撤 | 用【不羁之刃】拉开距离后立刻往回走，不要在换血后站着对拼 | 夏侯惇向指定目标方向扔出链刃，链刃飞向指定位置或击中敌人后会对范围内敌人造成物理，拉开之后是你回身打第二轮 |
| 压塔时机 | 【不羁之刃】用来压塔或逼对方回城，等对方位移交掉再顶上去 | 夏侯惇向指定目标方向扔出链刃，链刃飞向指定位置或击中敌人后会对范围内敌人造成物理，顶在塔前逼位能直接拆塔 |
| 转线支援 | 对方打野在中路消失就往中路靠，抢支援比补线值钱 | 对抗路转线晚一步，团战就是少一个人 |
| 单带 | 队友抱团时你在边路单带，不要跟着去挤团 | 团战你不在也能打，单带你不在就丢高地 |
