# 孙尚香（发育路）速查卡

> 千金重弩 · 射手 · 官方分路：发育路 · 快照 2026-11-12

## 实战连招（按顺序按）

- **对线换血消耗**：`1技能`
  - 在对方技能真空期打满伤害
  - 注意：技能落空后仍继续前压，换血变单方面挨打
- **追击与残血收割**：`1技能 → 2技能`
  - 把已经交掉关键技能的残血目标彻底收掉
  - 注意：位移留到残血才交，目标一个闪现或加速就脱离，交空后你被反打
- **残血逃生保命**：`1技能`
  - 拉开距离，把命保住而不是换人头
  - 注意：朝敌人方向交位移，等于主动送进控制范围
- **拆塔与清线**：`2技能`
  - 把优势转成塔与经济，而不是无意义换人头
  - 注意：把范围技能浪费在兵线上，或在对方塔下强开导致被反杀
- 官方连招原文：翻滚突袭：1→A→2→A→3　/　消耗连招：2→1→A　/　爆发连招：3→2→1→A　/　1→A→2→A→3　/　2→1→A　/　3→2→1→A

- **[实战要点]** 翻滚后强化普攻伤害爆炸
- **[实战要点]** 1技能翻滚可穿薄墙
- **[实战要点]** 大招击退自保
- **[实战要点]** 被动攻速加成让持续输出强
- **[官方 Tips]** 蓝色隐匿移速方便孙尚香更好的移动寻找输出位置，团战支援也比较迅速，物理攻击可以提伤害
- **[玩法定位]** 翻滚射手，千金重弩；翻滚强化普攻，爆发收割

### 发育路打法（这条英雄专属节奏）

| 节点 | 做法 | 为什么 |
| --- | --- | --- |
| 发育节奏 | 前期以补刀为主，【翻滚突袭】能打到的兵才去打，不要为了一两个残血兵进塔 | 射手前期死一次，节奏就断了，等级和装备都会落后 |
| 站位输出 | 站在自己塔前用【究极弩炮】打最远的那个目标，优先打前排或正在打你的那个人 | 孙尚香蓄力向指定方向发射一枚弩炮，站着不动输出才有安全输出 |
| 标记优先 | 看到【红莲爆弹】能挂上的目标优先集火，不要平均分配伤害 | 孙尚香朝指定位置投掷爆弹，对范围内敌人造成物理伤害并减少其移动速度，持续，标记对象承受的伤害更集中 |
| 自保 | 闪现留着打断或逃命，不要用来赶路 | 赶路用走路，闪现用来保命才有价值 |
| 拆塔 | 对方回城且兵线到位时拆塔，不要在塔下与人对峙 | 拆塔收益稳定，对峙收益不稳定 |
