# 小乔（中路）速查卡

> 恋之微风 · 法师 · 官方分路：中路 · 快照 2026-11-12

## 实战连招（按顺序按）

- **团战开团先手**：`2技能 → 3技能 → 1技能`
  - 用最短时间把对方关键位控住，把先手权换成团战收益
  - 注意：硬控落空或被对方前排挡下，后面所有技能都变成空放
- **草丛埋伏突袭**：`2技能`
  - 用草丛消除对方反应时间，靠控制先手换血或击杀
  - 注意：从草丛正面走出才放技能，等于告诉对方「草里有人」，对方会提前交位移
- **对线换血消耗**：`1技能 → 2技能`
  - 用最低成本的技能起手，确认对方状态后再决定是否打满
  - 注意：第一段落空后继续按后续技能，等于把所有技能一次性交到空气上
- **拆塔与清线**：`1技能`
  - 把优势转成塔与经济，而不是无意义换人头
  - 注意：把范围技能浪费在兵线上，或在对方塔下强开导致被反杀
- 官方连招原文：基础消耗：2→1→A　/　爆发秒人：闪现→3→2→1　/　团战输出：3→2→1→A→A　/　2→1→A　/　闪现→3→2→1　/　3→2→1→A→A

## 精华技巧

- **[实战要点]** 2技能控制接大招是核心连招
- **[实战要点]** 1技能扇子越远伤害越高
- **[实战要点]** 大招团战AOE爆炸
- **[实战要点]** 被动移速让支援很快
- **[官方 Tips]** 狩猎提升10％移速加成，对于被动具有加速效果的小乔来说，适合放风筝，可以进行中远距离的输出，机动性高
- **[玩法定位]** 爆发法师，恋之微风；二技能控制，大招流星范围伤害

### 中路节奏（这条英雄专属打法）

| 节点 | 做法 | 为什么 |
| --- | --- | --- |
| 清线优先 | 先把兵线清完再去支援，支援路上顺手用【绽放之舞】收掉兵线再进场 | 中路线权没了就去支援，等于有去无回 |
| 消耗距离 | 站在【绽放之舞】能打到的最远距离上poke，不要为了多打一下走进对方射程 | 小乔向指定方向扔出一把回旋飞行的扇子，射程优势本来就是你的核心资源 |
| 抢支援窗口 | 看到边路交火，在对方技能交空后用【甜蜜恋风】先手控住，不是开团了就到 | 早到 5 秒是接盘，晚到 5 秒是收尸 |
| 大招用途 | 【星华缭乱】用来压塔或封走位，不要用来清兵 | 小乔召唤流星并不断向附近的敌人坠落，召唤持续，每颗流星会造成法术伤害，每个敌人最，用在大招该解决的事情上 |
| 河道视野 | 把自己当第二个打野位，蹲对方从中路消失的路线 | 中路的视野优势来自草丛，不来自河道中央 |
