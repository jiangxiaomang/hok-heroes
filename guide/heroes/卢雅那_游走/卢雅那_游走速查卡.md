# 卢雅那（游走）速查卡

> 蛇焰使者 · 射手 · 官方分路：游走 · 快照 2026-11-12

## 实战连招（按顺序按）

- **蹲草绕后突袭**：`2技能 → 3技能 → 1技能`
  - 用位移取消读图时间，让对方来不及交控制
  - 注意：位移落点被地形卡住，或位移方向与目标相反，导致控技能甩空
- **追击与残血收割**：`2技能 → 1技能`
  - 把已经交掉关键技能的残血目标彻底收掉
  - 注意：位移留到残血才交，目标一个闪现或加速就脱离，交空后你被反打
- **残血逃生保命**：`2技能`
  - 拉开距离，把命保住而不是换人头
  - 注意：朝敌人方向交位移，等于主动送进控制范围
- **拆塔与清线**：`1技能`
  - 把优势转成塔与经济，而不是无意义换人头
  - 注意：把范围技能浪费在兵线上，或在对方塔下强开导致被反杀
- 官方连招原文：1穿墙-2-3石化-A-A-A（翻墙进场大招石化瞬间清屏）　/　2-1拉扯-A-3（防切反杀）

| 节点 | 做法 | 为什么 |
| --- | --- | --- |
| 保护人 | 站到己方 C 位与对方之间，用身体挡住对方第一轮技能 | C 位死一次，团战直接结束 |
| 蹲草开团 | 在对方必经草丛蹲着，等对方走到再交【蛇吻突袭】，控制留在能打多人或能打 C 位的位置 | 卢雅那在指定位置召唤火蛇，控制位置的收益大于控制时机 |
