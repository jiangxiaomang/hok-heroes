# 镜（打野）速查卡

> 破镜之刃 · 刺客 · 官方分路：打野 · 快照 2026-11-12

## 实战连招（按顺序按）

- **团战开团先手**：`3技能 → 1技能 → 2技能`
  - 用最短时间把对方关键位控住，把先手权换成团战收益
  - 注意：硬控落空或被对方前排挡下，后面所有技能都变成空放
- **蹲草绕后突袭**：`1技能 → 3技能 → 2技能`
  - 用位移取消读图时间，让对方来不及交控制
  - 注意：位移落点被地形卡住，或位移方向与目标相反，导致控技能甩空
- **对线换血消耗**：`2技能 → 3技能`
  - 用最低成本的技能起手，确认对方状态后再决定是否打满
  - 注意：第一段落空后继续按后续技能，等于把所有技能一次性交到空气上
- **追击与残血收割**：`1技能 → 2技能 → 3技能`
  - 把已经交掉关键技能的残血目标彻底收掉
  - 注意：位移留到残血才交，目标一个闪现或加速就脱离，交空后你被反打
- 官方连招原文：飞雷神：1→2→3→1→2→3　/　基础连招：1→A→2→A→3　/　反打连招：3→2→1→2　/　1→2→3→1→2→3　/　1→A→2→A→3　/　3→2→1→2

### 打野节奏（这条英雄专属路线）

| 节点 | 做法 | 为什么 |
| --- | --- | --- |
| 开局清野 | 先用【开锋】清掉第一圈野怪，技能循环转好再上 4 级 | 快速朝前突进并对路径上的敌人造成物理伤害和的减速，同时强化下次普攻，额外造成两次，前期把它转满才能在 4 级点形成等级差 |

| 位移绕后 | 从侧面草丛用【开锋】进场，落地角度选对方背后，别从正面走 | 快速朝前突进并对路径上的敌人造成物理伤害和的减速，同时强化下次普攻，额外造成两次，位移是取消读图和打反直觉的关键 |

| 跟团方式 | 队友先手后你再进，【见影】留到对方关键控制交完之后 | 你有硬控可以接第二段，但先手太早会被位移和净化反打 |
