# 海诺（中路）速查卡

> 命运之引 · 战士 · 官方分路：中路、对抗路 · 快照 2026-11-12

## 实战连招（按顺序按）

- **蹲草绕后突袭**：`2技能 → 1技能 → 3技能`
  - 用位移取消读图时间，让对方来不及交控制
  - 注意：位移落点被地形卡住，或位移方向与目标相反，导致控技能甩空
- **对线换血消耗**：`1技能`
  - 用最低成本的技能起手，确认对方状态后再决定是否打满
  - 注意：第一段落空后继续按后续技能，等于把所有技能一次性交到空气上
- **追击与残血收割**：`2技能 → 1技能`
  - 把已经交掉关键技能的残血目标彻底收掉
  - 注意：位移留到残血才交，目标一个闪现或加速就脱离，交空后你被反打
- **残血逃生保命**：`2技能 → 1技能`
  - 拉开距离，把命保住而不是换人头
  - 注意：朝敌人方向交位移，等于主动送进控制范围
- 官方连招原文：2命途游侠-3大招命运回溯-1命刃·追芒　/　1-2-3（双形态）

### 中路节奏（这条英雄专属打法）

| 节点 | 做法 | 为什么 |
| --- | --- | --- |
| 清线优先 | 先把兵线清完再去支援，支援路上顺手用【命刃·追芒/旋击】收掉兵线再进场 | 中路线权没了就去支援，等于有去无回 |
| 消耗距离 | 站在【命刃·追芒/旋击】能打到的最远距离上poke，不要为了多打一下走进对方射程 | 海诺技能命中敌人会对其叠加印记每命中个印记目标可减少冷却；远程：海诺用力掷出能量，射程优势本来就是你的核心资源 |
| 抢支援窗口 | 看到边路交火，在对方技能交空后用【命刃·追芒/旋击】先手控住，不是开团了就到 | 早到 5 秒是接盘，晚到 5 秒是收尸 |
| 大招用途 | 【命运回溯】用来压塔或封走位，不要用来清兵 | 海诺会在上一次远程状态最后的时间点留下记录，用在大招该解决的事情上 |
| 河道视野 | 把自己当第二个打野位，蹲对方从中路消失的路线 | 中路的视野优势来自草丛，不来自河道中央 |
