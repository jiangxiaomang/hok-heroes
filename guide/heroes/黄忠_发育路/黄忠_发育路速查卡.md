# 黄忠（发育路）速查卡

> 燃魂重炮 · 射手 · 官方分路：发育路 · 快照 2026-11-12

## 实战连招（按顺序按）

- **蹲草绕后突袭**：`3技能 → 2技能`
  - 用位移取消读图时间，让对方来不及交控制
  - 注意：位移落点被地形卡住，或位移方向与目标相反，导致控技能甩空
- **对线换血消耗**：`2技能`
  - 用最低成本的技能起手，确认对方状态后再决定是否打满
  - 注意：第一段落空后继续按后续技能，等于把所有技能一次性交到空气上
- **追击与残血收割**：`3技能 → 2技能`
  - 把已经交掉关键技能的残血目标彻底收掉
  - 注意：位移留到残血才交，目标一个闪现或加速就脱离，交空后你被反打
- **残血逃生保命**：`3技能 → 2技能`
  - 拉开距离，把命保住而不是换人头
  - 注意：朝敌人方向交位移，等于主动送进控制范围
- 官方连招原文：3大招重装炮台-2警戒地雷-1追击潜能　/　2-1-3（架炮推进）

## 精华技巧

- **[实战要点]** 炮台射程超远
- **[实战要点]** 2技能地雷减速
- **[实战要点]** 大招炮台AOE
- **[实战要点]** 守塔能力顶级
- **[官方 Tips]** 黄忠作为站桩输出，对移速没有需求，前期有1技能加速和2技能减速敌方需求也不大，因此主攻击和穿透，中后期无双的暴击效果配合无尽可以呈现出毁灭程
- **[玩法定位]** 架炮射手，重装炮台；大招架炮推进，需要队友保护

### 发育路打法（这条英雄专属节奏）

| 节点 | 做法 | 为什么 |
| --- | --- | --- |
| 发育节奏 | 前期以补刀为主，【追击潜能】能打到的兵才去打，不要为了一两个残血兵进塔 | 射手前期死一次，节奏就断了，等级和装备都会落后 |
| 站位输出 | 站在自己塔前用【追击潜能】打最远的那个目标，优先打前排或正在打你的那个人 | 黄忠激发自身潜能，提升移速，在内持续衰减，若黄忠处于炮台形态，则可瞬间退出炮台形，站着不动输出才有安全输出 |
| 集火规则 | 团战只打一个目标，开局就打【重装炮台】能覆盖到的位置 | 平均伤害谁也打不死，集中才有意义 |
| 自保 | 血量到一半就先退，用【警戒地雷】扛一下再回线，不要硬撑到残血 | 黄忠向指定区域布置一个可获取视野的地雷，对触碰目标造成物理伤害，并获取目标的视野，活着回到塔下才有下一波 |
| 拆塔 | 对方回城且兵线到位时拆塔，不要在塔下与人对峙 | 拆塔收益稳定，对峙收益不稳定 |
