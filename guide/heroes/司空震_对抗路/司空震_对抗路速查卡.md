# 司空震（对抗路）速查卡

> 雷霆之王 · 战士 · 官方分路：对抗路、打野 · 快照 2026-11-12

## 实战连招（按顺序按）

- **团战开团先手**：`2技能 → 3技能 → 1技能`
  - 用最短时间把对方关键位控住，把先手权换成团战收益
  - 注意：硬控落空或被对方前排挡下，后面所有技能都变成空放
- **草丛埋伏突袭**：`2技能`
  - 用草丛消除对方反应时间，靠控制先手换血或击杀
  - 注意：从草丛正面走出才放技能，等于告诉对方「草里有人」，对方会提前交位移
- **拆塔与清线**：`2技能`
  - 把优势转成塔与经济，而不是无意义换人头
  - 注意：把范围技能浪费在兵线上，或在对方塔下强开导致被反杀
- **打断与保护队友**：`2技能`
  - 在关键动作读条时把对方打断，或在队友被追时把人拉回来
  - 注意：控制交早，对手交了净化或加速后你进入空窗
- 官方连招原文：2狂雷击-3大招雷霆万钧-1奔雷疾　/　1-2-3（雷霆连招）

## 对抗路位打法要点

### 高分实战要点（这个英雄专属技巧）

| 要点 | 怎么用 | 口径 |
| --- | --- | --- |
| 大招变身期间伤害 | 围绕【雷霆万钧】用：大招变身期间伤害质变 | 实战要点口径 |
| 被动雷印叠满伤害 | 把被动叠到最高的那一波再进场，不要在被动没叠满的时候硬开 | 实战要点口径 |
| 位移 | 围绕【奔雷疾】用：1技能位移技能控制链 | 实战要点口径 |
| 免控 | 探草丛之前先想好退路，一旦位置暴露就用位移直接撤，不要留在原地 | 实战要点口径 |

### 对抗路打法（这条英雄专属打法）

| 节点 | 做法 | 为什么 |
| --- | --- | --- |
| 抢线 | 开局用【狂雷击】快速推线，把对方逼到塔下再打消耗 | 对抗路先手推线的人拥有换血主动权 |
| 换血后撤 | 换完血立刻后撤到兵线后方，让小兵替你挡第一轮技能 | 站桩换血是对抗路最常见的死法 |
| 压塔时机 | 【雷霆万钧】用来压塔或逼对方回城，等对方位移交掉再顶上去 | 司空震升入空中，化身为雷霆之王，顶在塔前逼位能直接拆塔 |
| 转线支援 | 对方打野在中路消失就往中路靠，抢支援比补线值钱 | 对抗路转线晚一步，团战就是少一个人 |
| 单带 | 队友抱团时你在边路单带，不要跟着去挤团 | 团战你不在也能打，单带你不在就丢高地 |
