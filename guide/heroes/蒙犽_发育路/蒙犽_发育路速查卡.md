# 蒙犽（发育路）速查卡

> 烈炮小子 · 射手 · 官方分路：发育路 · 快照 2026-11-12

## 实战连招（按顺序按）

- **草丛埋伏突袭**：`2技能`
  - 用草丛消除对方反应时间，靠控制先手换血或击杀
  - 注意：从草丛正面走出才放技能，等于告诉对方「草里有人」，对方会提前交位移
- **对线换血消耗**：`1技能 → 2技能`
  - 用最低成本的技能起手，确认对方状态后再决定是否打满
  - 注意：第一段落空后继续按后续技能，等于把所有技能一次性交到空气上
- **拆塔与清线**：`1技能`
  - 把优势转成塔与经济，而不是无意义换人头
  - 注意：把范围技能浪费在兵线上，或在对方塔下强开导致被反杀
- **打断与保护队友**：`2技能`
  - 在关键动作读条时把对方打断，或在队友被追时把人拉回来
  - 注意：控制交早，对手交了净化或加速后你进入空窗
- 官方连招原文：2爆裂重炮-3大招飞弹援袭-1狂轰火线　/　1-2-3（扫射压塔）

### 发育路打法（这条英雄专属节奏）

| 节点 | 做法 | 为什么 |
| --- | --- | --- |
| 发育节奏 | 前期以补刀为主，【爆裂重炮】能打到的兵才去打，不要为了一两个残血兵进塔 | 射手前期死一次，节奏就断了，等级和装备都会落后 |
| 站位输出 | 站在自己塔前用【爆裂重炮】打最远的那个目标，优先打前排或正在打你的那个人 | 蒙犽朝指定方向发射一枚重炮，对触碰的敌人造成物理伤害并减速持续；重炮触碰敌人或者，站着不动输出才有安全输出 |
| 标记优先 | 看到【飞弹援袭】能挂上的目标优先集火，不要平均分配伤害 | 蒙犽开始搜索周围的环境，搜索范围内的敌人受到来自友军英雄的伤害时，会标记目标位置，标记对象承受的伤害更集中 |
| 自保 | 闪现留着打断或逃命，不要用来赶路 | 赶路用走路，闪现用来保命才有价值 |
| 拆塔 | 对方回城且兵线到位时拆塔，不要在塔下与人对峙 | 拆塔收益稳定，对峙收益不稳定 |
