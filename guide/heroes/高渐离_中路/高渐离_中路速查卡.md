# 高渐离（中路）速查卡

> 叛逆吟游 · 法师 · 官方分路：中路 · 快照 2026-11-12

## 实战连招（按顺序按）

- **对线换血消耗**：`1技能`
  - 在对方技能真空期打满伤害
  - 注意：技能落空后仍继续前压，换血变单方面挨打
- **拆塔与清线**：`1技能`
  - 把优势转成塔与经济，而不是无意义换人头
  - 注意：把范围技能浪费在兵线上，或在对方塔下强开导致被反杀
- 官方连招原文：3大招魔音贯耳-1狂歌-2离歌　/　闪现-3-2-1（进场秒C）

### 中路节奏（这条英雄专属打法）

| 节点 | 做法 | 为什么 |
| --- | --- | --- |
| 清线优先 | 先把兵线清完再去支援，支援路上顺手用【狂歌】收掉兵线再进场 | 中路线权没了就去支援，等于有去无回 |
| 消耗距离 | 只在技能命中且对方没有位移时上前消耗 | 没有距离优势时，多一次上前就多一次被抓 |
| 抢支援窗口 | 看到边路交火，对方技能交空后再到 | 对方技能空掉的那几秒才是支援窗口 |
| 大招用途 | 【魔音贯耳】用来压塔或封走位，不要用来清兵 | 渐离释放激情，每进行一次演奏，对附近敌人造成法术伤害，持续，用在大招该解决的事情上 |
| 河道视野 | 把自己当第二个打野位，蹲对方从中路消失的路线 | 中路的视野优势来自草丛，不来自河道中央 |

### 阶段节奏（前期 → 中期 → 后期）

| 阶段 | 怎么打 | 要点 |
| --- | --- | --- |
| 前期 | 前期1技能消耗（这一阶段主要靠【狂歌】） | 大招期间持续AOE伤害 |
| 中期 | 中期大招进场AOE（这一阶段主要靠【狂歌】） | 1技能可穿透小兵 |
| 后期 | 后期闪现大招毁灭团战（这一阶段主要靠【狂歌】） | 2技能减速留人 |
