# 云缨（打野）速查卡

> 燎原之心 · 战士 · 官方分路：打野 · 快照 2026-11-12

## 实战连招（按顺序按）

- **团战开团先手**：`1技能 → 2技能 → 3技能`
  - 用最短时间把对方关键位控住，把先手权换成团战收益
  - 注意：硬控落空或被对方前排挡下，后面所有技能都变成空放
- **蹲草绕后突袭**：`2技能 → 1技能 → 3技能`
  - 用位移取消读图时间，让对方来不及交控制
  - 注意：位移落点被地形卡住，或位移方向与目标相反，导致控技能甩空
- **追击与残血收割**：`2技能 → 1技能`
  - 把已经交掉关键技能的残血目标彻底收掉
  - 注意：位移留到残血才交，目标一个闪现或加速就脱离，交空后你被反打
- **残血逃生保命**：`2技能`
  - 拉开距离，把命保住而不是换人头
  - 注意：朝敌人方向交位移，等于主动送进控制范围
- 官方连招原文：2追云-3大招驭火兴风-1断月　/　1-2-3（枪意连招）

## 打野位打法要点

### 高分实战要点（这个英雄专属技巧）

| 要点 | 怎么用 | 口径 |
| --- | --- | --- |
| 技能命中累积枪意 | 打出去的技能要记得收回来，拿不回来这套循环就断了，进场前先看清还能用几次 | 实战要点口径 |
| 枪意满层强化普攻 | 进场后先打普攻把层数攒起来，攒满再放技能 | 实战要点口径 |
| 连招节奏决定伤害 | 优先保证这一段能完整打出来，中途不要贪别的目标 | 实战要点口径 |
| 大招范围大适合团 | 围绕【逐星】用：大招范围大适合团战 | 实战要点口径 |

### 打野节奏（这条英雄专属路线）

| 节点 | 做法 | 为什么 |
| --- | --- | --- |
| 开局清野 | 先用【断月】清掉第一圈野怪，技能循环转好再上 4 级 | 云缨举枪向前方上挑后下劈，前期把它转满才能在 4 级点形成等级差 |
| 4 级第一波 | 盯压线最前的那个人，【逐星】落地接【追云】把伤害补满 | 云缨引燃“掠火”枪尖，向前方区域来回突击，每段都对敌人造成物理伤害和击飞，大招先手才有跟上的空间 |
| 位移绕后 | 从侧面草丛用【追云】进场，落地角度选对方背后，别从正面走 | 云缨提枪蓄力冲锋，获得最高增加移速，结束时向前突进横扫，对敌人造成物理伤害和减速，位移是取消读图和打反直觉的关键 |
| 惩戒节点 | 只交给能改变结果的节点：抢红隼、反野惩戒、收掉残血野怪 | 开局就交掉惩戒，4 级那波抓人你就没有第二条命 |
| 资源时间 | 空间之灵 2:00 前把路线排好，双龙 10:00 前站好位置 | 资源点的时间差，就是团队经济的差 |
| 跟团方式 | 队友先手后你再进，【逐星】留到对方关键控制交完之后 | 你有硬控可以接第二段，但先手太早会被位移和净化反打 |
