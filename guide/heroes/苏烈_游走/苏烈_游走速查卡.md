# 苏烈（游走）速查卡

> 不屈铁壁 · 辅助 · 官方分路：游走、对抗路 · 快照 2026-11-12

## 实战连招（按顺序按）

- **团战开团先手**：`1技能 → 3技能`
  - 用最短时间把对方关键位控住，把先手权换成团战收益
  - 注意：硬控落空或被对方前排挡下，后面所有技能都变成空放
- **草丛埋伏突袭**：`1技能`
  - 用草丛消除对方反应时间，靠控制先手换血或击杀
  - 注意：从草丛正面走出才放技能，等于告诉对方「草里有人」，对方会提前交位移
- **对线换血消耗**：`1技能`
  - 用最低成本的技能起手，确认对方状态后再决定是否打满
  - 注意：第一段落空后继续按后续技能，等于把所有技能一次性交到空气上
- **拆塔与清线**：`3技能`
  - 把优势转成塔与经济，而不是无意义换人头
  - 注意：把范围技能浪费在兵线上，或在对方塔下强开导致被反杀
- 官方连招原文：2所向披靡-3大招豪烈万军-1烽烟踏破　/　1-2-3（控制链）

### 游走职责（这条英雄专属打法）

| 节点 | 做法 | 为什么 |
| --- | --- | --- |
| 保护人 | 站到己方 C 位与对方之间，用身体挡住对方第一轮技能 | C 位死一次，团战直接结束 |
| 蹲草开团 | 在对方必经草丛蹲着，等对方走到再交【烽烟踏破】，控制留在能打多人或能打 C 位的位置 | 强化下三次普通攻击，攻击造成物理伤害，第三次攻击会将范围内的敌人击飞，控制位置的收益大于控制时机 |
| 开团与反开 | 对方先手落地后再交【豪烈万军】，这时他们没有净化和位移 | 苏烈举起柱子开始蓄力，释放时会用力将柱子砸向地面，对敌人造成物理伤害并将其击飞；，后手开团比先手开团更稳 |
| 跟打野 | 打野在哪条线你就出现在哪条线 | 分散的游走等于没有游走 |
| 撤退信号 | C 位血量危险时立刻喊退，不要硬保 | 救不回来就一起死，亏两波 |

### 阶段节奏（前期 → 中期 → 后期）

| 阶段 | 怎么打 | 要点 |
