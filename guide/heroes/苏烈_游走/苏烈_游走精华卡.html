游走位打法要点

高分实战要点（这个英雄专属技巧）
  • 复活机制独特：团战前先站到己方 C 位身后，大招收割时保护范围要盖住他，别自己冲出去打
  • 大招蓄力范围击飞：围绕【豪烈万军】用：大招蓄力范围击飞
  • 铁壁防御姿态：记住这条：铁壁防御姿态，进场前先想好怎么用
游走职责（这条英雄专属打法）
  • 保护人：站到己方 C 位与对方之间，用身体挡住对方第一轮技能
  • 蹲草开团：在对方必经草丛蹲着，等对方走到再交【烽烟踏破】，控制留在能打多人或能打 C 位的位置
  • 开团与反开：对方先手落地后再交【豪烈万军】，这时他们没有净化和位移
阶段节奏（前期 → 中期 → 后期）
  • 前期：前期铁壁消耗（这一阶段主要靠【烽烟踏破】）
  • 中期：中期复活站起来（这一阶段主要靠【烽烟踏破】）
  • 后期：后期大招蓄力开团（这一阶段主要靠【烽烟踏破】）
