# 米莱狄（中路）速查卡

> 筑城者 · 法师 · 官方分路：中路 · 快照 2026-11-12

## 实战连招（按顺序按）

- **团战开团先手**：`3技能 → 1技能`
  - 用最短时间把对方关键位控住，把先手权换成团战收益
  - 注意：硬控落空或被对方前排挡下，后面所有技能都变成空放
- **蹲草绕后突袭**：`3技能 → 1技能`
  - 用位移取消读图时间，让对方来不及交控制
  - 注意：位移落点被地形卡住，或位移方向与目标相反，导致控技能甩空
- **对线换血消耗**：`1技能 → 3技能`
  - 用最低成本的技能起手，确认对方状态后再决定是否打满
  - 注意：第一段落空后继续按后续技能，等于把所有技能一次性交到空气上
- **追击与残血收割**：`3技能 → 1技能`
  - 把已经交掉关键技能的残血目标彻底收掉
  - 注意：位移留到残血才交，目标一个闪现或加速就脱离，交空后你被反打
- 官方连招原文：空中力量-强制入侵-浩劫磁场（基础连招）　/　浩劫磁场-空中力量-强制入侵（爆发连招）
