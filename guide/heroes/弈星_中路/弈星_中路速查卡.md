# 弈星（中路）速查卡

> 天元之弈 · 法师 · 官方分路：中路 · 快照 2026-11-12

## 实战连招（按顺序按）

- **团战开团先手**：`3技能 → 1技能`
  - 用最短时间把对方关键位控住，把先手权换成团战收益
  - 注意：硬控落空或被对方前排挡下，后面所有技能都变成空放
- **草丛埋伏突袭**：`3技能`
  - 用草丛消除对方反应时间，靠控制先手换血或击杀
  - 注意：从草丛正面走出才放技能，等于告诉对方「草里有人」，对方会提前交位移
- **对线换血消耗**：`1技能 → 3技能`
  - 用最低成本的技能起手，确认对方状态后再决定是否打满
  - 注意：第一段落空后继续按后续技能，等于把所有技能一次性交到空气上
- **拆塔与清线**：`2技能`
  - 把优势转成塔与经济，而不是无意义换人头
  - 注意：把范围技能浪费在兵线上，或在对方塔下强开导致被反杀
- 官方连招原文：飞攻-镇神-万变之局（基础连招）　/　万变之局-飞攻-镇神（爆发连招）

### 中路节奏（这条英雄专属打法）

| 节点 | 做法 | 为什么 |
| --- | --- | --- |
| 清线优先 | 先把兵线清完再去支援，支援路上顺手用【镇神】收掉兵线再进场 | 中路线权没了就去支援，等于有去无回 |
| 消耗距离 | 只在技能命中且对方没有位移时上前消耗 | 没有距离优势时，多一次上前就多一次被抓 |
| 抢支援窗口 | 看到边路交火，在对方技能交空后用【飞攻】先手控住，不是开团了就到 | 早到 5 秒是接盘，晚到 5 秒是收尸 |
| 大招用途 | 【万变之局】用来压塔或封走位，不要用来清兵 | 弈星以自身位置为棋盘一角，画出一个虚空棋盘，后棋盘完全成型，对范围内敌人击飞，用在大招该解决的事情上 |
| 河道视野 | 把自己当第二个打野位，蹲对方从中路消失的路线 | 中路的视野优势来自草丛，不来自河道中央 |
