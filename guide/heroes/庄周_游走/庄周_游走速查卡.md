# 庄周（游走）速查卡

> 逍遥梦幻 · 辅助 · 官方分路：游走 · 快照 2026-11-12

## 实战连招（按顺序按）

- **草丛埋伏突袭**：`1技能`
  - 用草丛消除对方反应时间，靠控制先手换血或击杀
  - 注意：从草丛正面走出才放技能，等于告诉对方「草里有人」，对方会提前交位移
- **对线换血消耗**：`1技能`
  - 用最低成本的技能起手，确认对方状态后再决定是否打满
  - 注意：第一段落空后继续按后续技能，等于把所有技能一次性交到空气上
- **拆塔与清线**：`1技能`
  - 把优势转成塔与经济，而不是无意义换人头
  - 注意：把范围技能浪费在兵线上，或在对方塔下强开导致被反杀
- **打断与保护队友**：`1技能`
  - 在关键动作读条时把对方打断，或在队友被追时把人拉回来
  - 注意：控制交早，对手交了净化或加速后你进入空窗
- 官方连招原文：2蝴蝶效应-3大招天人合一-1化蝶　/　1-2-3（保护队友）

- **[实战要点]** 被动免伤+回血
- **[实战要点]** 2技能减速消耗

## 游走位打法要点

### 高分实战要点（这个英雄专属技巧）

| 要点 | 怎么用 | 口径 |
| --- | --- | --- |
| 免控 | 围绕【天人合一】用：大招群体免控是核心 | 实战要点口径 |
| 回血 | 按血线情况决定进不进：血量落到被动生效的那条线再上，血多的时候进场等于白挨打 | 实战要点口径 |
| 减速 | 围绕【蝴蝶效应】用：2技能减速消耗 | 实战要点口径 |
| 控制 | 记住这条：解控能力克制控制阵容，进场前先想好怎么用 | 实战要点口径 |

### 游走职责（这条英雄专属打法）

| 节点 | 做法 | 为什么 |
| --- | --- | --- |
| 保护人 | 站到己方 C 位与对方之间，用【天人合一】顶住第一轮爆发 | 庄周幻化梦域保护队友和自身，你的价值是让 C 位能站住输出 |
| 蹲草开团 | 在对方必经草丛蹲着，等对方走到再交【化蝶】，控制留在能打多人或能打 C 位的位置 | 庄周进入自然梦境并幻化出蝴蝶飞向指定方向，控制位置的收益大于控制时机 |
| 开团与反开 | 叫队友开团，你在侧面接第二段控制 | 双开团比单开团更难被反打 |
| 跟打野 | 打野在哪条线你就出现在哪条线 | 分散的游走等于没有游走 |
| 撤退信号 | C 位血量危险时立刻喊退，不要硬保 | 救不回来就一起死，亏两波 |

### 阶段节奏（前期 → 中期 → 后期）

| 阶段 | 怎么打 | 要点 |
| --- | --- | --- |
| 前期 | 前期解控保人（这一阶段主要靠【天人合一】） | 大招群体免控是核心 |
| 中期 | 中期蝴蝶消耗（这一阶段主要靠【天人合一】） | 被动免伤+回血 |
| 后期 | 后期大招群体免控（这一阶段主要靠【天人合一】） | 2技能减速消耗 |
