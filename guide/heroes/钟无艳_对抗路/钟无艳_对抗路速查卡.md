# 钟无艳（对抗路）速查卡

> 野蛮之锤 · 战士 · 官方分路：对抗路、打野 · 快照 2026-11-12

## 实战连招（按顺序按）

- **蹲草绕后突袭**：`1技能 → 3技能 → 2技能`
  - 用位移取消读图时间，让对方来不及交控制
  - 注意：位移落点被地形卡住，或位移方向与目标相反，导致控技能甩空
- **对线换血消耗**：`1技能`
  - 用最低成本的技能起手，确认对方状态后再决定是否打满
  - 注意：第一段落空后继续按后续技能，等于把所有技能一次性交到空气上
- **追击与残血收割**：`1技能 → 2技能`
  - 把已经交掉关键技能的残血目标彻底收掉
  - 注意：位移留到残血才交，目标一个闪现或加速就脱离，交空后你被反打
- **残血逃生保命**：`1技能 → 3技能`
  - 拉开距离，把命保住而不是换人头
  - 注意：朝敌人方向交位移，等于主动送进控制范围
- 官方连招原文：2狂飙突进-3大招飓风之锤-1狂飙突进　/　1-2-3（突进控制）

## 精华技巧

- **[实战要点]** 被动石化概率看脸但伤害稳定
- **[实战要点]** 2技能中心命中伤害最高
- **[实战要点]** 大招期间石化敌人可触发多次被动
- **[实战要点]** 闪现+2技能贴脸是核心连招
- **[官方 Tips]** 调和提高最大生命以及移速加成，提升回复能力；鹰眼和异变提高物理攻击和物理穿透，在一定程度上的提高了钟无艳的伤害
- **[玩法定位]** 调和提高最大生命以及移速加成，提升回复能力；鹰眼和异变提高物理攻击和物理穿透

### 对抗路打法（这条英雄专属打法）

| 节点 | 做法 | 为什么 |
| --- | --- | --- |
| 抢线 | 开局用【狂飙突进】快速推线，把对方逼到塔下再打消耗 | 对抗路先手推线的人拥有换血主动权 |
| 换血后撤 | 用【狂飙突进】拉开距离后立刻往回走，不要在换血后站着对拼 | 钟无艳向前突进，下一次普攻强化为重击，重击将造成物理伤害和减速，持续，拉开之后是你回身打第二轮 |
| 压塔时机 | 【飓风之锤】用来压塔或逼对方回城，等对方位移交掉再顶上去 | 钟无艳抡起大锤持续旋转并增加自身移速每造成物理伤害，对外圈的敌人造成额外伤害，顶在塔前逼位能直接拆塔 |
| 转线支援 | 对方打野在中路消失就往中路靠，抢支援比补线值钱 | 对抗路转线晚一步，团战就是少一个人 |
| 单带 | 队友抱团时你在边路单带，不要跟着去挤团 | 团战你不在也能打，单带你不在就丢高地 |
