# 少司缘（游走）速查卡

> 聆愿之祝 · 辅助 · 官方分路：游走 · 快照 2026-11-12

## 实战连招（按顺序按）

- **团战开团先手**：`2技能 → 1技能 → 3技能`
  - 用最短时间把对方关键位控住，把先手权换成团战收益
  - 注意：硬控落空或被对方前排挡下，后面所有技能都变成空放
- **蹲草绕后突袭**：`1技能 → 2技能 → 3技能`
  - 用位移取消读图时间，让对方来不及交控制
  - 注意：位移落点被地形卡住，或位移方向与目标相反，导致控技能甩空
- **追击与残血收割**：`1技能 → 3技能 → 2技能`
  - 把已经交掉关键技能的残血目标彻底收掉
  - 注意：位移留到残血才交，目标一个闪现或加速就脱离，交空后你被反打
- **残血逃生保命**：`1技能`
  - 拉开距离，把命保住而不是换人头
  - 注意：朝敌人方向交位移，等于主动送进控制范围
- 官方连招原文：2-2-1-1-3（锁敌定身飞入开大群体抬血）　/　1-1-A-2-2（救护残血C位反打）

## 游走位打法要点

### 高分实战要点（这个英雄专属技巧）

| 要点 | 怎么用 | 口径 |
| --- | --- | --- |
| 红线连队友增益 | 优先保证这一段能完整打出来，中途不要贪别的目标 | 来自官方实战要点 |
| 牵线距离有限注意 | 打出去的技能要记得收回来，拿不回来这套循环就断了，进场前先看清还能用几次 | 来自官方实战要点 |
| 大招可同时连多个 | 围绕【因缘际会】用：大招可同时连多个目标 | 少司缘指挥成群的缘崽向前拥簇飞行，对沿途友方英雄施加"良缘"和生命回 |
| 被动攒缘分换增益 | 把被动叠到最高的那一波再进场，不要在被动没叠满的时候硬开 | 来自官方实战要点 |

### 游走职责（这条英雄专属打法）

| 节点 | 做法 | 为什么 |
| --- | --- | --- |
| 保护人 | 站到己方 C 位与对方之间，用【两同心】顶住第一轮爆发 | 少司缘祝愿友方英雄"良缘"并回复生命生命，你的价值是让 C 位能站住输出 |
| 蹲草开团 | 在对方必经草丛蹲着，等对方走到再交【怨离别】，控制留在能打多人或能打 C 位的位置 | 少司缘警示敌方"冤缘"造成显形、造成法术伤害并惩罚金币，结束时造成法术伤害，控制位置的收益大于控制时机 |
| 开团与反开 | 对方先手落地后再交【因缘际会】，这时他们没有净化和位移 | 少司缘指挥成群的缘崽向前拥簇飞行，对沿途友方英雄施加"良缘"和生命回复，后手开团比先手开团更稳 |
| 跟打野 | 打野在哪条线你就出现在哪条线 | 分散的游走等于没有游走 |
| 撤退信号 | C 位血量危险时立刻喊退，不要硬保 | 救不回来就一起死，亏两波 |
