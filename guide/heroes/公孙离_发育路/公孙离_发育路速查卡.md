# 公孙离（发育路）速查卡

> 幻舞玲珑 · 射手 · 官方分路：发育路 · 快照 2026-11-12

## 实战连招（按顺序按）

- **团战开团先手**：`3技能 → 2技能`
  - 用最短时间把对方关键位控住，把先手权换成团战收益
  - 注意：硬控落空或被对方前排挡下，后面所有技能都变成空放
- **草丛埋伏突袭**：`3技能`
  - 用草丛消除对方反应时间，靠控制先手换血或击杀
  - 注意：从草丛正面走出才放技能，等于告诉对方「草里有人」，对方会提前交位移
- **拆塔与清线**：`2技能`
  - 把优势转成塔与经济，而不是无意义换人头
  - 注意：把范围技能浪费在兵线上，或在对方塔下强开导致被反杀
- **打断与保护队友**：`3技能`
  - 在关键动作读条时把对方打断，或在队友被追时把人拉回来
  - 注意：控制交早，对手交了净化或加速后你进入空窗
- 官方连招原文：伞的舞蹈：1→A→2→A→3→A　/　极限逃生：2→1→3　/　消耗连招：1→A→2→A　/　1→A→2→A→3→A　/　2→1→3　/　1→A→2→A

## 发育路位打法要点

### 高分实战要点（这个英雄专属技巧）

| 要点 | 怎么用 | 口径 |
| --- | --- | --- |
| 位移 | 靠移动把距离拉开再打，不要站着对拼，走位比多打一下更重要 | 来自官方实战要点 |
| 控制 | 围绕【孤鹜断霞】用：大招击退+控制 | 阿离击退前方的敌人 |
| 被动枫叶印记 | 先确认自己的被动条件满没满，没满就先拉扯或者清线，别硬进场 | 来自官方实战要点 |
| 操作上限极高 | 记住这条：操作上限极高，进场前先想好怎么用 | 来自官方实战要点 |

### 发育路打法（这条英雄专属节奏）

| 节点 | 做法 | 为什么 |
| --- | --- | --- |
| 发育节奏 | 前期以补刀为主，【岑中归月】能打到的兵才去打，不要为了一两个残血兵进塔 | 射手前期死一次，节奏就断了，等级和装备都会落后 |
| 站位输出 | 站在自己塔前用【霜叶舞】打最远的那个目标，优先打前排或正在打你的那个人 | 阿离旋转起操控纸伞飞旋，站着不动输出才有安全输出 |
| 集火规则 | 团战只打一个目标，开局就打【孤鹜断霞】能覆盖到的位置 | 平均伤害谁也打不死，集中才有意义 |
| 自保 | 闪现留着打断或逃命，不要用来赶路 | 赶路用走路，闪现用来保命才有价值 |
| 拆塔 | 对方回城且兵线到位时拆塔，不要在塔下与人对峙 | 拆塔收益稳定，对峙收益不稳定 |
