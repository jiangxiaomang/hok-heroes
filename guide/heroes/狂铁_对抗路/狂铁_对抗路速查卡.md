# 狂铁（对抗路）速查卡

> 战车意志 · 战士 · 官方分路：对抗路 · 快照 2026-11-12

## 实战连招（按顺序按）

- **团战开团先手**：`2技能 → 3技能 → 1技能`
  - 用最短时间把对方关键位控住，把先手权换成团战收益
  - 注意：硬控落空或被对方前排挡下，后面所有技能都变成空放
- **蹲草绕后突袭**：`2技能 → 3技能 → 1技能`
  - 用位移取消读图时间，让对方来不及交控制
  - 注意：位移落点被地形卡住，或位移方向与目标相反，导致控技能甩空
- **对线换血消耗**：`1技能 → 2技能`
  - 用最低成本的技能起手，确认对方状态后再决定是否打满
  - 注意：第一段落空后继续按后续技能，等于把所有技能一次性交到空气上
- **追击与残血收割**：`2技能 → 1技能`
  - 把已经交掉关键技能的残血目标彻底收掉
  - 注意：位移留到残血才交，目标一个闪现或加速就脱离，交空后你被反打
- 官方连招原文：碎裂之刃-强袭风暴-力场压制（基础连招）　/　力场压制-碎裂之刃-强袭风暴（爆发连招）

### 对抗路打法（这条英雄专属打法）

| 节点 | 做法 | 为什么 |
| --- | --- | --- |
| 抢线 | 开局用【力场压制】快速推线，把对方逼到塔下再打消耗 | 对抗路先手推线的人拥有换血主动权 |
| 换血后撤 | 用【强袭风暴】拉开距离后立刻往回走，不要在换血后站着对拼 | 狂铁向前冲锋，冲锋路径上的敌人受到物理伤害，拉开之后是你回身打第二轮 |
| 压塔时机 | 【力场压制】用来压塔或逼对方回城，等对方位移交掉再顶上去 | 将武器砸向地面，造成物理伤害和减速，顶在塔前逼位能直接拆塔 |
| 转线支援 | 对方打野在中路消失就往中路靠，抢支援比补线值钱 | 对抗路转线晚一步，团战就是少一个人 |
| 单带 | 队友抱团时你在边路单带，不要跟着去挤团 | 团战你不在也能打，单带你不在就丢高地 |
