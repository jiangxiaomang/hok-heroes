# 曹操（对抗路）速查卡

> 鲜血枭雄 · 战士 · 官方分路：对抗路、打野 · 快照 2026-11-12

## 实战连招（按顺序按）

- **团战开团先手**：`1技能 → 3技能`
  - 用最短时间把对方关键位控住，把先手权换成团战收益
  - 注意：硬控落空或被对方前排挡下，后面所有技能都变成空放
- **草丛埋伏突袭**：`1技能`
  - 用草丛消除对方反应时间，靠控制先手换血或击杀
  - 注意：从草丛正面走出才放技能，等于告诉对方「草里有人」，对方会提前交位移
- **拆塔与清线**：`2技能`
  - 把优势转成塔与经济，而不是无意义换人头
  - 注意：把范围技能浪费在兵线上，或在对方塔下强开导致被反杀
- **打断与保护队友**：`1技能`
  - 在关键动作读条时把对方打断，或在队友被追时把人拉回来
  - 注意：控制交早，对手交了净化或加速后你进入空窗
- 官方连招原文：霸道之刃-纵横天下-浴血枭雄（基础连招）　/　浴血枭雄-霸道之刃-纵横天下（爆发连招）

## 对抗路位打法要点

### 高分实战要点（这个英雄专属技巧）

| 要点 | 怎么用 | 口径 |
| --- | --- | --- |
| 回血 | 围绕【浴血枭雄】用：大招期间普攻回血，站撸换命 | 曹操以鲜血意志强化大剑，解除自身控制效果并回复已损生命 |
| 位移 | 围绕【霸道之刃】用：1技能三段位移可穿薄墙 | 曹操发起斩击突袭，对路径上的敌人造成物理伤害 |
| 2技能剑气远端伤 | 围绕【纵横天下】用：2技能剑气远端伤害更高 | 曹操挥出强大剑气，对路径上的敌人造成物理伤害并减少其移速，持续 |
| 减速 | 靠移动把距离拉开再打，不要站着对拼，走位比多打一下更重要 | 来自官方实战要点 |

### 对抗路打法（这条英雄专属打法）

| 节点 | 做法 | 为什么 |
| --- | --- | --- |
| 抢线 | 开局用【纵横天下】快速推线，把对方逼到塔下再打消耗 | 对抗路先手推线的人拥有换血主动权 |
| 换血后撤 | 换完血立刻后撤到兵线后方，让小兵替你挡第一轮技能 | 站桩换血是对抗路最常见的死法 |
| 压塔时机 | 【浴血枭雄】用来压塔或逼对方回城，等对方位移交掉再顶上去 | 曹操以鲜血意志强化大剑，解除自身控制效果并回复已损生命，顶在塔前逼位能直接拆塔 |
| 转线支援 | 对方打野在中路消失就往中路靠，抢支援比补线值钱 | 对抗路转线晚一步，团战就是少一个人 |
| 单带 | 队友抱团时你在边路单带，不要跟着去挤团 | 团战你不在也能打，单带你不在就丢高地 |
