# 金蝉（中路）速查卡

> 渡世行者 · 法师 · 官方分路：中路、游走 · 快照 2026-11-12

## 实战连招（按顺序按）

- **草丛埋伏突袭**：`1技能`
  - 用草丛消除对方反应时间，靠控制先手换血或击杀
  - 注意：从草丛正面走出才放技能，等于告诉对方「草里有人」，对方会提前交位移
- **对线换血消耗**：`2技能 → 1技能`
  - 用最低成本的技能起手，确认对方状态后再决定是否打满
  - 注意：第一段落空后继续按后续技能，等于把所有技能一次性交到空气上
- **拆塔与清线**：`2技能`
  - 把优势转成塔与经济，而不是无意义换人头
  - 注意：把范围技能浪费在兵线上，或在对方塔下强开导致被反杀
- **打断与保护队友**：`1技能`
  - 在关键动作读条时把对方打断，或在队友被追时把人拉回来
  - 注意：控制交早，对手交了净化或加速后你进入空窗
- 官方连招原文：2九环之杖-3大招轮回之印-1紧箍之咒　/　1-2-3（禁锢救人）

## 中路位打法要点

### 高分实战要点（这个英雄专属技巧）

| 要点 | 怎么用 | 口径 |
| --- | --- | --- |
| 位移 | 靠移动把距离拉开再打，不要站着对拼，走位比多打一下更重要 | 实战要点口径 |
| 减伤 | 围绕【轮回之印】用：大招群体减伤 | 实战要点口径 |
| 1技能袈裟伤害 | 围绕【紧箍之咒】用：1技能袈裟伤害 | 实战要点口径 |
| 被动金身免伤 | 先确认自己的被动条件满没满，没满就先拉扯或者清线，别硬进场 | 实战要点口径 |

### 中路节奏（这条英雄专属打法）

| 节点 | 做法 | 为什么 |
| --- | --- | --- |
| 清线优先 | 先把兵线清完再去支援，支援路上顺手用【九环之杖】收掉兵线再进场 | 中路线权没了就去支援，等于有去无回 |
| 消耗距离 | 只在技能命中且对方没有位移时上前消耗 | 没有距离优势时，多一次上前就多一次被抓 |
| 抢支援窗口 | 看到边路交火，在对方技能交空后用【紧箍之咒】先手控住，不是开团了就到 | 早到 5 秒是接盘，晚到 5 秒是收尸 |
| 大招用途 | 【轮回之印】用来压塔或封走位，不要用来清兵 | 短暂解放轮回之印，件神器回归原本的力量，用在大招该解决的事情上 |
| 河道视野 | 把自己当第二个打野位，蹲对方从中路消失的路线 | 中路的视野优势来自草丛，不来自河道中央 |

### 阶段节奏（前期 → 中期 → 后期）

| 阶段 | 怎么打 | 要点 |
| --- | --- | --- |
| 前期 | 前期袈裟消耗（这一阶段主要靠【轮回之印】） | 紧箍咒限制位移 |
| 中期 | 中期紧箍咒限制（这一阶段主要靠【轮回之印】） | 大招群体减伤 |
| 后期 | 后期大招群体减伤（这一阶段主要靠【轮回之印】） | 1技能袈裟伤害 |
