# 亚瑟（对抗路）速查卡

> 圣骑之力 · 战士 · 官方分路：对抗路、打野 · 快照 2026-11-12

## 实战连招（按顺序按）

- **团战开团先手**：`3技能 → 1技能`
  - 用最短时间把对方关键位控住，把先手权换成团战收益
  - 注意：硬控落空或被对方前排挡下，后面所有技能都变成空放
- **蹲草绕后突袭**：`3技能 → 1技能`
  - 用位移取消读图时间，让对方来不及交控制
  - 注意：位移落点被地形卡住，或位移方向与目标相反，导致控技能甩空
- **追击与残血收割**：`3技能 → 1技能`
  - 把已经交掉关键技能的残血目标彻底收掉
  - 注意：位移留到残血才交，目标一个闪现或加速就脱离，交空后你被反打
- **残血逃生保命**：`3技能`
  - 拉开距离，把命保住而不是换人头
  - 注意：朝敌人方向交位移，等于主动送进控制范围
- 官方连招原文：2回旋打击-3大招圣剑裁决-1誓约之盾　/　1-2-3（追击沉默）

| 节点 | 做法 | 为什么 |
| --- | --- | --- |
| 抢线 | 开局用【誓约之盾】快速推线，把对方逼到塔下再打消耗 | 对抗路先手推线的人拥有换血主动权 |
| 换血后撤 | 用【圣剑裁决】拉开距离后立刻往回走，不要在换血后站着对拼 | 亚瑟举起圣剑跃向敌方英雄，造成敌方英雄最大生命法术伤害并将其击飞，拉开之后是你回身打第二轮 |
| 压塔时机 | 【圣剑裁决】用来压塔或逼对方回城，等对方位移交掉再顶上去 | 亚瑟举起圣剑跃向敌方英雄，造成敌方英雄最大生命法术伤害并将其击飞，顶在塔前逼位能直接拆塔 |

| 单带 | 队友抱团时你在边路单带，不要跟着去挤团 | 团战你不在也能打，单带你不在就丢高地 |
