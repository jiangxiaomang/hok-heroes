# 牛魔（游走）速查卡

> 精英酋长 · 辅助 · 官方分路：游走 · 快照 2026-11-12

## 实战连招（按顺序按）

- **团战开团先手**：`2技能 → 3技能 → 1技能`
  - 用最短时间把对方关键位控住，把先手权换成团战收益
  - 注意：硬控落空或被对方前排挡下，后面所有技能都变成空放
- **蹲草绕后突袭**：`2技能 → 3技能 → 1技能`
  - 用位移取消读图时间，让对方来不及交控制
  - 注意：位移落点被地形卡住，或位移方向与目标相反，导致控技能甩空
- **对线换血消耗**：`1技能 → 2技能`
  - 用最低成本的技能起手，确认对方状态后再决定是否打满
  - 注意：第一段落空后继续按后续技能，等于把所有技能一次性交到空气上
- **追击与残血收割**：`2技能 → 1技能`
  - 把已经交掉关键技能的残血目标彻底收掉
  - 注意：位移留到残血才交，目标一个闪现或加速就脱离，交空后你被反打
- 官方连招原文：2横行霸道-3大招山崩地裂-1咆哮之斧　/　闪现-3-2-1（大闪开团）

## 游走位打法要点

### 高分实战要点（这个英雄专属技巧）

| 要点 | 怎么用 | 口径 |
| --- | --- | --- |
| 控制 | 蹲草要等对方走到你选好的那个点再动手，提前露头这一波就废了 | 来自官方实战要点 |
| 减伤 | 优先保证这一段能完整打出来，中途不要贪别的目标 | 来自官方实战要点 |
| 开团 | 围绕【山崩地裂】用：大招群体击飞开团 | 牛魔短暂蓄力后向指定方向以巨斧猛力劈开大地 |
| 被动坚韧免伤 | 先确认自己的被动条件满没满，没满就先拉扯或者清线，别硬进场 | 来自官方实战要点 |

### 游走职责（这条英雄专属打法）

| 节点 | 做法 | 为什么 |
| --- | --- | --- |
| 保护人 | 站到己方 C 位与对方之间，用身体挡住对方第一轮技能 | C 位死一次，团战直接结束 |
| 蹲草开团 | 在对方必经草丛蹲着，等对方走到再交【横行霸道】，控制留在能打多人或能打 C 位的位置 | 牛魔朝指定方向冲锋，对路径上的敌人造成物理伤害并击飞，控制位置的收益大于控制时机 |
| 开团与反开 | 对方先手落地后再交【山崩地裂】，这时他们没有净化和位移 | 牛魔短暂蓄力后向指定方向以巨斧猛力劈开大地，对范围内敌人造成物理伤害并将其击飞，后手开团比先手开团更稳 |
| 跟打野 | 打野在哪条线你就出现在哪条线 | 分散的游走等于没有游走 |
| 撤退信号 | C 位血量危险时立刻喊退，不要硬保 | 救不回来就一起死，亏两波 |
