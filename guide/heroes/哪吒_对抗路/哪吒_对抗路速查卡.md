# 哪吒（对抗路）速查卡

> 桀骜炎枪 · 战士 · 官方分路：对抗路、打野 · 快照 2026-11-12

## 实战连招（按顺序按）

- **团战开团先手**：`2技能 → 3技能 → 1技能`
  - 用最短时间把对方关键位控住，把先手权换成团战收益
  - 注意：硬控落空或被对方前排挡下，后面所有技能都变成空放
- **草丛埋伏突袭**：`2技能`
  - 用草丛消除对方反应时间，靠控制先手换血或击杀
  - 注意：从草丛正面走出才放技能，等于告诉对方「草里有人」，对方会提前交位移
- **对线换血消耗**：`1技能 → 2技能`
  - 用最低成本的技能起手，确认对方状态后再决定是否打满
  - 注意：第一段落空后继续按后续技能，等于把所有技能一次性交到空气上
- **拆塔与清线**：`1技能`
  - 把优势转成塔与经济，而不是无意义换人头
  - 注意：把范围技能浪费在兵线上，或在对方塔下强开导致被反杀
- 官方连招原文：火焰三尖-混天绫·-乾坤·天（基础连招）　/　乾坤·天-火焰三尖-混天绫·（爆发连招）

## 对抗路位打法要点

### 高分实战要点（这个英雄专属技巧）

| 要点 | 怎么用 | 口径 |
| --- | --- | --- |
| 大招全图锁定无法 | 围绕【乾坤·天降】用：大招全图锁定无法躲避 | 实战要点口径 |
| 吸血 | 按血线情况决定进不进：血量落到被动生效的那条线再上，血多的时候进场等于白挨打 | 实战要点口径 |
| 飞人时无敌帧可躲 | 优先保证这一段能完整打出来，中途不要贪别的目标 | 实战要点口径 |
| 残血 | 靠这套循环把血线拉回来，所以不要在血不满的时候硬接团战 | 实战要点口径 |

### 对抗路打法（这条英雄专属打法）

| 节点 | 做法 | 为什么 |
| --- | --- | --- |
| 抢线 | 开局用【火焰三尖枪】快速推线，把对方逼到塔下再打消耗 | 对抗路先手推线的人拥有换血主动权 |
| 换血后撤 | 换完血立刻后撤到兵线后方，让小兵替你挡第一轮技能 | 站桩换血是对抗路最常见的死法 |
| 压塔时机 | 【乾坤·天降】用来压塔或逼对方回城，等对方位移交掉再顶上去 | 哪吒升上天空并对敌方所有英雄施加乾坤圈，释放后将获得其视野并打断回城，随后可选择，顶在塔前逼位能直接拆塔 |
| 转线支援 | 对方打野在中路消失就往中路靠，抢支援比补线值钱 | 对抗路转线晚一步，团战就是少一个人 |
| 单带 | 队友抱团时你在边路单带，不要跟着去挤团 | 团战你不在也能打，单带你不在就丢高地 |
