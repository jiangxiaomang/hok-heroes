# 鲁班大师（游走）速查卡

> 神匠 · 辅助 · 官方分路：游走 · 快照 2026-11-12

## 实战连招（按顺序按）

- **团战开团先手**：`1技能 → 3技能`
  - 用最短时间把对方关键位控住，把先手权换成团战收益
  - 注意：硬控落空或被对方前排挡下，后面所有技能都变成空放
- **蹲草绕后突袭**：`1技能 → 3技能`
  - 用位移取消读图时间，让对方来不及交控制
  - 注意：位移落点被地形卡住，或位移方向与目标相反，导致控技能甩空
- **追击与残血收割**：`1技能 → 3技能`
  - 把已经交掉关键技能的残血目标彻底收掉
  - 注意：位移留到残血才交，目标一个闪现或加速就脱离，交空后你被反打
- **残血逃生保命**：`1技能 → 2技能`
  - 拉开距离，把命保住而不是换人头
  - 注意：朝敌人方向交位移，等于主动送进控制范围
- 官方连招原文：助推跳跃-助手驰援-强力收纳（基础连招）　/　强力收纳-助推跳跃-助手驰援（爆发连招）

## 游走位打法要点

### 高分实战要点（这个英雄专属技巧）

| 要点 | 怎么用 | 口径 |
| --- | --- | --- |
| 机械臂拉扯敌人 | 靠移动把距离拉开再打，不要站着对拼，走位比多打一下更重要 | 实战要点口径 |
| 机关室困人 | 优先保证这一段能完整打出来，中途不要贪别的目标 | 实战要点口径 |
| 控制 | 围绕【强力收纳】用：大招领域控制 | 实战要点口径 |
| 被动机械强化 | 先确认自己的被动条件满没满，没满就先拉扯或者清线，别硬进场 | 实战要点口径 |

### 游走职责（这条英雄专属打法）

| 节点 | 做法 | 为什么 |
| --- | --- | --- |
| 保护人 | 站到己方 C 位与对方之间，用【助手驰援】顶住第一轮爆发 | 鲁班大师为一名队友和自己赋予护盾，并在他和自己之间创造链接队友确认交互后会立即位，你的价值是让 C 位能站住输出 |
| 蹲草开团 | 在对方必经草丛蹲着，等对方走到再交【助推跳跃】，控制留在能打多人或能打 C 位的位置 | 鲁班大师借助机械臂喷气动力向前跳跃，控制位置的收益大于控制时机 |
| 开团与反开 | 叫队友开团，你在侧面接第二段控制 | 双开团比单开团更难被反打 |
| 跟打野 | 打野在哪条线你就出现在哪条线 | 分散的游走等于没有游走 |
| 撤退信号 | C 位血量危险时立刻喊退，不要硬保 | 救不回来就一起死，亏两波 |
