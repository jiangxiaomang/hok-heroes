# 芈月（对抗路）速查卡

> 永恒之月 · 法师 · 官方分路：对抗路、打野 · 快照 2026-11-12

## 实战连招（按顺序按）

- **拆塔与清线**：`1技能`
  - 把优势转成塔与经济，而不是无意义换人头
  - 注意：把范围技能浪费在兵线上，或在对方塔下强开导致被反杀
- 官方连招原文：3大招暗影之月-1痛苦冲击-2幻翼仆从　/　1-2-3-A（消耗吸血）

### 对抗路打法（这条英雄专属打法）

| 节点 | 做法 | 为什么 |
| --- | --- | --- |
| 抢线 | 开局用【痛苦冲击】快速推线，把对方逼到塔下再打消耗 | 对抗路先手推线的人拥有换血主动权 |
| 换血后撤 | 换完血立刻后撤到兵线后方，让小兵替你挡第一轮技能 | 站桩换血是对抗路最常见的死法 |
| 压塔时机 | 【暗影之月】用来压塔或逼对方回城，等对方位移交掉再顶上去 | 芈月遁入暗影，增加移动速度并免疫所有效果，持续，顶在塔前逼位能直接拆塔 |
| 转线支援 | 对方打野在中路消失就往中路靠，抢支援比补线值钱 | 对抗路转线晚一步，团战就是少一个人 |
| 单带 | 队友抱团时你在边路单带，不要跟着去挤团 | 团战你不在也能打，单带你不在就丢高地 |
