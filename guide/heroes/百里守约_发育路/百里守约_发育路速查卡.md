# 百里守约（发育路）速查卡

> 静谧之眼 · 射手 · 官方分路：发育路 · 快照 2026-11-12

## 实战连招（按顺序按）

- **对线换血消耗**：`2技能`
  - 在对方技能真空期打满伤害
  - 注意：技能落空后仍继续前压，换血变单方面挨打
- **追击与残血收割**：`3技能 → 2技能`
  - 把已经交掉关键技能的残血目标彻底收掉
  - 注意：位移留到残血才交，目标一个闪现或加速就脱离，交空后你被反打
- **残血逃生保命**：`3技能`
  - 拉开距离，把命保住而不是换人头
  - 注意：朝敌人方向交位移，等于主动送进控制范围
- **拆塔与清线**：`2技能`
  - 把优势转成塔与经济，而不是无意义换人头
  - 注意：把范围技能浪费在兵线上，或在对方塔下强开导致被反杀
- 官方连招原文：2狂风之息-3大招逃脱-1静谧之眼　/　2-2-3（狙击连招）

### 发育路打法（这条英雄专属节奏）

| 节点 | 做法 | 为什么 |
| --- | --- | --- |
| 发育节奏 | 前期以补刀为主，【静谧之眼】能打到的兵才去打，不要为了一两个残血兵进塔 | 射手前期死一次，节奏就断了，等级和装备都会落后 |
| 站位输出 | 站在自己塔前用【静谧之眼】打最远的那个目标，优先打前排或正在打你的那个人 | 百里守约在脚下布置一个视野装置，获得的全部视野，站着不动输出才有安全输出 |
| 集火规则 | 团战只打一个目标，开局就打【逃脱】能覆盖到的位置 | 平均伤害谁也打不死，集中才有意义 |
| 自保 | 闪现留着打断或逃命，不要用来赶路 | 赶路用走路，闪现用来保命才有价值 |
| 拆塔 | 对方回城且兵线到位时拆塔，不要在塔下与人对峙 | 拆塔收益稳定，对峙收益不稳定 |
