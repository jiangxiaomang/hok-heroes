# 伽罗（发育路）速查卡

> 破魔之箭 · 射手 · 官方分路：发育路 · 快照 2026-11-12

## 实战连招（按顺序按）

- **草丛埋伏突袭**：`2技能`
  - 用草丛消除对方反应时间，靠控制先手换血或击杀
  - 注意：从草丛正面走出才放技能，等于告诉对方「草里有人」，对方会提前交位移
- **对线换血消耗**：`1技能 → 2技能`
  - 用最低成本的技能起手，确认对方状态后再决定是否打满
  - 注意：第一段落空后继续按后续技能，等于把所有技能一次性交到空气上
- **拆塔与清线**：`1技能`
  - 把优势转成塔与经济，而不是无意义换人头
  - 注意：把范围技能浪费在兵线上，或在对方塔下强开导致被反杀
- **打断与保护队友**：`2技能`
  - 在关键动作读条时把对方打断，或在队友被追时把人拉回来
  - 注意：控制交早，对手交了净化或加速后你进入空窗
- 官方连招原文：2静默之箭-3大招纯净之域-1渡灵之箭　/　1-2-3（减速消耗）

## 精华技巧

- **[实战要点]** 射程全英雄最远
- **[实战要点]** 1技能切换射程
- **[实战要点]** 大招移速+射程
- **[实战要点]** 站位安全超远输出

## 发育路位打法要点

### 高分实战要点（这个英雄专属技巧）

| 要点 | 怎么用 | 口径 |
| --- | --- | --- |
| 射程全英雄最远 | 站在对方够不到你的位置输出，保持距离比多打一下更重要 | 来自官方实战要点 |
| 1技能切换射程 | 围绕【渡灵之箭】用：1技能切换射程 | 伽罗展开长弓，攻击间隔增长并提升射程 |
| 大招移速+射程 | 围绕【纯净之域】用：大招移速+射程 | 伽罗在身边张开法阵持续并可手动关闭，提升范围内自己的暴击率和攻击速度 |
| 站位安全超远输出 | 优先保证这一段能完整打出来，中途不要贪别的目标 | 来自官方实战要点 |

### 发育路打法（这条英雄专属节奏）

| 节点 | 做法 | 为什么 |
| --- | --- | --- |
| 发育节奏 | 前期以补刀为主，【纯净之域】能打到的兵才去打，不要为了一两个残血兵进塔 | 射手前期死一次，节奏就断了，等级和装备都会落后 |
| 站位输出 | 站在自己塔前用【渡灵之箭】打最远的那个目标，优先打前排或正在打你的那个人 | 伽罗展开长弓，攻击间隔增长并提升射程，站着不动输出才有安全输出 |
| 集火规则 | 团战只打一个目标，开局就打【纯净之域】能覆盖到的位置 | 平均伤害谁也打不死，集中才有意义 |
| 自保 | 闪现留着打断或逃命，不要用来赶路 | 赶路用走路，闪现用来保命才有价值 |
| 拆塔 | 对方回城且兵线到位时拆塔，不要在塔下与人对峙 | 拆塔收益稳定，对峙收益不稳定 |

| 阶段 | 怎么打 | 要点 |

| 后期 | 后期超远射程站桩（这一阶段主要靠【纯净之域】） | 大招移速+射程 |
